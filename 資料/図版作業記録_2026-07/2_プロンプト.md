## 4.　第33章_熱の効果とthermal-dose.png　【上書き】

```
美容皮膚科医向けの生化学教科書に載せる、教科書調の説明図を1枚作ってください。
この図は「熱で細胞に何が起きるか」の基準になる図で、教材全体の温度の定義をここで固定します。

【この図で一目で分からせたいこと】
同じ「熱」でも、温度と時間の組み合わせで細胞の運命は変わる。そして
「タンパク質が変性すること」と「細胞が死ぬこと」は別のレイヤーである。

【構成】横長。上下2段に分ける。
■上段：温度帯（縦に4つの帯を積む。数値の境界を必ず明示する）
  40〜45℃　：HSP（heat shock protein）が誘導される。細胞は生き延びて修復に回る
  50〜60℃　：酵素活性の低下、可逆的なストレス
  60〜65℃　：collagen の熱変性・即時収縮（＝タンパク変性。細胞死ではない）
  65〜70℃以上：凝固壊死（coagulative necrosis）
■下段：同じ温度軸に対して「細胞の運命」を別レイヤーとして並べる
  生存して修復 → ストレス応答 → アポトーシス → 凝固壊死
  上段と下段の境界がずれていること（変性≠死）が視覚的に分かるように

さらに横方向に「時間」の軸を薄く重ね、温度×時間＝熱量（thermal dose）であることを示す。
短時間・高温と長時間・低温が同じ帯に届きうることを矢印で。

図の下に注記を1行：「HIFUの熱凝固点（TCP）は、瞬間的にこの表の凝固壊死帯に入る」

【スタイル】クリーンな医学教科書調。パステル配色（低温＝寒色、高温＝暖色のグラデーション）。
背景は白。影・立体感・3Dは使わない。境界の数値は必ず読める大きさで。
ラベルは日本語だが、専門用語は英語のまま（HSP, collagen, thermal dose, coagulative necrosis）。
```

## 8.　第47章_美白外用の作用点.png　【上書き・骨格＋薬剤オーバーレイ】

```

【この図で一目で分からせたいこと】
美白剤は「どこで止めるか」で6つのグループに分けられる。同じ工程を狙う剤と、
別の工程を狙う剤があり、それが併用の考え方につながる。

【骨格】メラニン合成の経路を、下記の反応段階まで降ろして描いてください（これが土台）。
  tyrosine →（tyrosinase）→ DOPA →（tyrosinase）→ dopaquinone
  → DOPAchrome →（DCT/TYRP2）→ DHICA →（TYRP1）→ eumelanin
  （分岐して cysteinyl-DOPA → pheomelanin）

   ・rucinol、4-n-butylresorcinol ── tyrosinase と TYRP1 を阻害

     ※「既にある色に働きうる」数少ない作用
   ・glutathione ── dopaquinone と結合して pheomelanin 側へ流す
④ メラノソームの成熟・酵素の寿命（stage I〜IV の位置に）
   ・linoleic acid ── tyrosinase の分解を促す
⑤ 転送を止める（メラノサイト → keratinocyte の矢印に印）
   ・niacinamide
   ・PAR-2 阻害（serine protease inhibitor）
⑥ 排出を早める（keratinocyte のターンオーバーに印）
   ・レチノイド
   ・AHA・ケミカルピーリング
   ※ここで入れ替わるのは「渡ったメラニンを持つ keratinocyte」であって
     メラノサイト内のメラニンではない、と注記

【最重要】①〜⑥の番号と色を分け、右側または下部に凡例を置いて
「どの剤がどの工程か」を一覧で引けるようにしてください。
剤名は多いので、文字が小さくなりすぎないよう横長を強めにとってください。

【スタイル】クリーンな医学教科書調。パステル配色。背景は白。影・立体感・3Dは使わない。

（tyrosinase, TYRP1, DCT/TYRP2, tyrosine, DOPA, dopaquinone, eumelanin, pheomelanin,
```
