# 平易版の仕様 ―― 「平易版／専門版」の切り替え

同じ内容を、**専門版**（現行の本文）と**平易版**（看護師・美容医療従事者向け）で切り替えて読めるようにする。
2026-08-06 に著者が指定した仕様をここに置く。本文の書き方の規約は `CLAUDE.md`。
**新サイトに含めるかは未決定**（当面は本編だけで公開している）。

---

## 何のための機能か

読者が増える。いまの本文は臨床医向けに書いてあり、看護師・カウンセラーがそのまま読むには専門用語の密度が高い。
かといって**内容を薄めた別冊を作るのではない**。同じ章・同じ図・同じ結論のまま、**文の作りだけを変える**。

だから守るべき線は一本しかない。**平易版と専門版で、読者が持ち帰る結論が変わってはいけない。**

## 表示仕様

| | |
|---|---|
| 切り替えUI | ページ上部に「**読み方：平易版／専門版**」のトグル |
| 初期表示 | **専門版**（現行の読者が既定） |
| 切り替えの単位 | ページ全体。段落ごとに個別トグルはしない |
| 状態の保持 | 一度選んだら他の章へ移っても維持する |
| URL | **1つ**。版ごとにURLを分けない |
| 章構成・見出し・節番号 | **共通**。平易版だけ章立てが変わることはない |
| 図版 | **共通**。図は作り直さない |

図を2種類作らない理由は制作量。51点以上あり、2バージョンにすると片方を直すたびにもう片方がズレる。
**図はそのまま、キャプションと本文だけが平易版になる。**

## 記法

本文Markdownの中に両版を併記する。**別ファイルに分けない**（分けると必ず片方が古くなる）。

```markdown
真皮の質は、fibroblast が ECM を作る速さと、MMP で壊す速さの差で決まります。

::: easy
真皮の質は、線維芽細胞（コラーゲンなどを作る細胞）が「作る速さ」と「壊す速さ」の
どちらに傾いているかで決まります。
:::
```

- `::: easy` … `:::` で囲んだブロックが**平易版のときだけ**表示される
- 直前の段落が**専門版のときだけ**表示される
- **`::: easy` が付いていない段落は、両方の版に共通で出る**

3つ目が重要。**全文を書き直す必要はない。** 難しい段落にだけ平易版を足せば動く。
表・図・Evidence meter・参考文献は、そのまま共通で出してよい。

## 書くときのルール

著者の指定は6つ。実際に書くときの判断基準まで開くと、こうなる。

### 1. 1文を短くする
主語と述語が1組。「〜し、〜され、〜となる」を3文に割る。目安は1文40字前後。

### 2. 難しい用語は言い換える
英語のまま置いている語のうち、**言い換えても意味が痩せないもの**を日本語にする。
`fibroblast` → 線維芽細胞、`turnover` → 入れ替わり、`flux` → 流れる量。

### 3. 必須用語には短い説明を添える
**用語を全部消すのではない。** 残す語は残して、初出でカッコに一言入れる。

> 専門版：真皮線維芽細胞はコラーゲンを産生します。
> 平易版：線維芽細胞（肌のハリを支える細胞）は、コラーゲンを作ります。

残す語の判断：**その章の骨に関わる語、施術の説明で実際に使われている語は残す。** 消してよいのは、細部の分子名。

### 4. 細かな機序は圧縮する
中間ステップを畳んでよい。**ただし畳むのは経路であって、結論ではない。**

> 専門版：AMPK が ULK1 をリン酸化し、autophagy が誘導されます。
> 平易版：エネルギーが足りなくなると、細胞は古い部品を分解して片づけ始めます。

### 5. 数値・禁忌・注意点・断定の強さは変えない ―― **最重要**
ここだけは平易化の対象外。**そのまま持ってくる。**

- 数値を「だいたい」「ほとんど」に丸めない
- 禁忌・注意点は削らない。短くもしない
- **「〜と言われています」「ヒトでは未確認です」を「〜です」に強めない**
- Evidence meter の区分（確立した生化学／製剤ごとに検証が必要／未確立）は動かさない

### 6. 図版は共通にする
図は差し替えない。図のキャプションだけ平易版を用意してよい。

## やってはいけないこと

| | なぜ |
|---|---|
| 結論を変える | 版が違えば結論も違う教材は、教材として成立しない |
| 留保を落とす | 「機序としては可能／ヒトでは未検証」の切り分けがこの教材の値打ち |
| 断定を強める | 平易な文は断定調になりやすい。**ここが最大の事故ポイント** |
| 数値を丸める | 「9割以上」は「ほとんど」ではない |
| 誤解を招く簡略化 | 本文がわざわざ否定している誤解を、平易版で復活させない |
| 章の骨を変える | 骨は1本。版が違っても同じ骨を通す |
| エピソードを足す | 「〜という患者さんが来ます」のような創作はしない（`CLAUDE.md`） |

## 良い例・悪い例（細胞とは何かの実文から）

### 例1　keratinocyte

> **専門版**：表皮の9割以上。基底層で分裂し、扁平化・脱核して角層の"レンガ"になる。

> ⭕ **平易版**：表皮の細胞の9割以上を占めます。いちばん下の層（基底層）で分裂し、上へ押し上げられながら平たくなり、最後に核を失って角層の"レンガ"になります。

> ❌ 表皮のほとんどの細胞です。だんだん変化して角質になります。
> — 「9割以上」を「ほとんど」に丸めた（ルール5違反）。「脱核」という要点も消えている。

### 例2　melanocyte

> **専門版**：色の濃さは細胞数の差ではなく、作る量と渡し方・分布の差。

> ⭕ **平易版**：肌の色の濃さは、メラノサイトの数の差ではありません。作るメラニンの量と、周りの細胞への渡し方・散らばり方の差です。

> ❌ メラノサイトが多いと、肌の色が濃くなります。
> — **本文がわざわざ否定している誤解を、平易版で復活させている。** 平易化ではなく改竄。

### 例3　断定の強さ

> **専門版**：血中の NAD 関連指標が上がっても、標的組織の NAD⁺ が増えたことにはなりません。

> ⭕ **平易版**：血液の検査値が上がっても、皮膚など目的の場所で NAD⁺ が増えたとは言えません。ここはまだ確かめられていません。

> ❌ NMN を飲むと、皮膚の NAD⁺ が増えます。
> — 未検証の矢印を断定に変えている。**最も重い事故。**

## 進め方

1. `build_site.py` に `::: easy` の解釈とトグルUIを実装する
2. **細胞とは何かだけ**平易版を書く
3. **著者がトーンを判定する**。ここが本番。合っていなければ2に戻る
4. トーン確定後、残りの章へ広げる

**いきなり全章を書かない。** 大変なのは書く量ではなく「看護師さん向けのトーンとはどれか」を決めることで、
それが決まる前に56章書くと、方向が違ったときに全部やり直しになる。

平易版を足す優先順位は、**基礎章（第1〜7部）から**。各論（美容皮膚科以降）は施術名が出てくるぶん、
もともと看護師さんにも読みやすい。
