> **この章の前提**：[[melanocytes]]（メラニンを作って配る仕組み）・[[epidermis]]（角層とターンオーバー）・[[glycation]]（AGE架橋）
>
> **役割分担**：**色素の訴え（しみ・肝斑・くすみ）の正典はこの章**です。メラノサイトの生理——合成・成熟・転送・分布——は → [[melanocytes]]。

> 「しみ」に対して並ぶ手段は、ハイドロキノン、トラネキサム酸、ニコチン酸アミド、レチノイド、レーザー、IPL。「くすみ」に対しては、ピーリング、抗酸化、糖化対策。**どちらも一つの名前で呼ばれていますが、名前の中身は一つではありません。**

## この章の一言

> **見えている色は結果です。それを作り続けている上流がどの層にあるかで、届く手段が変わります。**
>
> 表皮で完結するしみと、上流が真皮にあるしみは、同じ褐色斑でも別物です。**くすみに至っては、色素だけの話ですらありません。**

## 1　色の訴えを、上流の層で分ける

[[melanocytes]]で見たとおり、メラニンは作られただけでは色になりません。ケラチノサイトへ渡り、核の上に並び、ターンオーバーで出ていく。**見えている色は、このパイプラインの出口です。**

だから「色を薄くする」介入を考えるとき、問うべきは**出口を回し続けているものが、どこにあるか**です。

| 訴え | 何が起きているか | 上流はどこか |
|---|---|---|
| **日光黒子・老人性色素斑**（solar lentigo） | 慢性UVによる境界明瞭な褐色斑 | **表皮**。メラノサイトの活性・数が局所的に上がっている |
| **そばかす**（ephelides） | 遺伝的素因（*MC1R* 多型）＋UV | **表皮**。境界不明瞭な小斑で、UVで濃くなる |
| **炎症後色素沈着**（PIH） | 炎症のあとにメラニンが表皮〜真皮に残る | **炎症そのもの**。鎖を止めなければ繰り返す |
| **肝斑**（melasma） | 左右対称の淡褐色斑。難治・再発性 | **真皮**。表皮のメラノサイトを叩いても上流が残る |
| **くすみ** | 明るさ・透明感の低下。境界を持たない | **複数の層**。メラニン以外の要素が混ざる |

**上の3つと下の2つで、手段の届き方が変わります。** 表皮で完結するものは表皮に届く手段で動きますが、上流が別の層にあるものは、出口だけを叩いても戻ります。

![5つの色の訴えを、上流がどの層にあるかで並べた図。左から日光黒子・そばかす（上流＝表皮のメラノサイト）、PIH（上流＝炎症の鎖）、肝斑（上流＝真皮：DEJ・血管・老化線維芽細胞・肥満細胞・ホルモン）、くすみ（上流＝角層・メラニン・糖化・血流の複数層）。皮膚の断面図の上に、それぞれの上流の位置を色分けして重ねる。右端に共通の結論「見えている色は出口。上流の層が違えば、届く手段も違う」](figures/pigmentation_色の訴えを分ける.png)

## 2　表皮で完結するもの ―― 日光黒子とそばかす

日光黒子は、慢性的なUV曝露を受けた部位で**メラノサイトの活性と数が局所的に上がった**状態です。境界が明瞭で、表皮に色素がとどまります。そばかすは遺伝的素因（*MC1R* 多型）が背景にあり、UVで濃くなります。

**この2つは、上流も出口も表皮にあります。** [[melanocytes]]の入口①（UV→p53→α-MSH→MC1R→MITF）を断つこと——つまり**遮光**——が予防の本体で、できてしまった色素については表皮に届く手段が素直に効きます。

**ただし「表皮で完結する」ことと「再発しない」ことは別です。** UV曝露が続けば、同じ場所で同じことが起こります。

## 3　PIH ―― 炎症が色に変わる鎖

炎症後色素沈着（PIH）は、ニキビ・施術・外傷といった**炎症のあと**にメラニンが残った状態です。上流は色素ではなく炎症で、機序は一本の鎖になっています。

> 熱・微小損傷 → ケラチノサイト由来メディエータ（**α-MSH・PGE2・SCF・ET-1**）→ **MC1R / c-KIT** → **MITF↑** → **tyrosinase↑**

PGE2 の入口は、[[melanocytes]]で見た **plasmin 経路**です。**だから「炎症を長引かせない」がPIH予防の本体**であって、色素を止める薬が本体ではありません。

**PIE と混同しないこと。** 炎症後紅斑（PIE：post-inflammatory erythema）は**ヘモグロビン由来の赤み**で、色素ではありません（→ [[erythema]]）。見た目が似ていても標的が違うので、同じ手段では動きません。

真皮まで炎症が及んだ場合、メラニンが真皮に落ちて長期化します。**表皮性か真皮性かで、消えるまでの時間の桁が変わります。**

![PIHの鎖を一本の流れで示す図。左端の入力（ニキビ・施術・外傷による熱と微小損傷）から、ケラチノサイト由来メディエータ（α-MSH・PGE2・SCF・ET-1）、受容体（MC1R・c-KIT）、MITF↑、tyrosinase↑、メラニン産生へ。PGE2の入口として plasmin 経路を分岐で描き込む。下段に、表皮にとどまる場合と真皮へ落ちる場合を並べ、消退までの時間の桁が違うことを示す。右下に「PIE（ヘモグロビン由来の赤み）は色素ではない」という区別を別枠で置く](figures/pigmentation_PIHの鎖.png)

## 4　肝斑 ―― 上流が真皮にある

肝斑は左右対称の淡褐色斑で、難治性・再発性です。**表皮メラノサイトの活性亢進だけでは説明できません。**

近年、肝斑は「色素の病気」であると同時に、**光老化・血管・ホルモンが絡む慢性疾患**として理解されるようになりました。出口を回し続けている上流が、表皮ではなく真皮側にあるからです。

![肝斑の色素環境を支える6要因。DEJ破綻とpendulous melanocyte、血管・VEGF、老化fibroblastのSASP（SCF・bFGF）、mast cellの脱顆粒、estrogenと可視光・熱、ROS増加とNrf2／HO-1防御低下がmelanocyteを刺激し、MITF→tyrosinase→melanin産生へ収束する。表皮だけを剥がしても真皮の促進環境が残れば再燃しやすい。](figures/pigmentation_肝斑の真皮軸.png)

**肝斑の真皮軸＝6因子**（本教材では、しみを扱うどの章でもこの6つで統一します）。

1. **基底膜（DEJ）の破綻**：慢性UV・MMPで表皮–真皮境界が壊れ、メラノサイトやメラニンが真皮側へ垂れ落ちる（**pendulous melanocyte**、真皮メラニン）。真皮に落ちた色素は表皮の美白剤が届きにくく、消えにくい（DEJの構成は → [[epidermis]]）。
2. **血管増生とVEGF**：肝斑病変では血管が増えていることが示されている。血管側の因子（VEGF・ET-1など）がメラノサイトを刺激し、**赤みと色素が共存**する（内皮の3挙動は → [[endothelium]]）。血管を意識せず色素だけ狙うと取りこぼす。
3. **老化線維芽細胞のSASP**：光老化で老化した線維芽細胞（→ [[senescence]]）が **SCF（→c-KIT）・bFGF** などのパラクリン因子を出してメラノサイトを刺激する。**真皮側の環境が色素形成を維持している。**
4. **肥満細胞（mast cell）**：肝斑病変部で増加が報告される。トリプターゼによる**基底膜・弾性線維の分解**、ヒスタミン・トリプターゼによる**血管拡張と血管新生**、protease による PAR-2 系の活性化を通じて、①②に重ねて効く。
5. **エストロゲンと可視光/熱**：妊娠・経口避妊薬で悪化しやすく、メラノサイトは **estrogen/progesterone受容体**を持つ。肝斑はUVだけでなく**可視光（とくにブルーライト）や熱でも悪化**しうる。「UVカットだけ」では守り切れず、**熱刺激がかえって再燃を招くことがある**——熱と炎症は §3 の鎖そのものだからです。
6. **酸化ストレスとNrf2/HO-1の低下**：肝斑病変ではROSが増えている一方で、抗酸化の司令塔である **Nrf2 とその標的 HO-1 の応答がむしろ低下**していると報告される（→ [[oxidative-stress]]）。「**酸化が強いのに守りが弱い**」。ROS自体が melanogenesis を刺激するため、これが慢性化の一因になる。

**見えている褐色斑は出口の結果で、それを作り続けている上流――基底膜・血管・老化線維芽細胞・肥満細胞・ホルモン・酸化ストレス――は、表皮のメラノサイトを叩いても消えません。** だから再発します。[[erythema]]の赤みと同じ構図で、「結果の色を消す」より「**駆動している上流を鎮める**」を土台に置く発想が要ります。

ただし**肝斑は多因子性で、機序はなお研究途上**です。「メラノサイトだけの問題」でも「線維芽細胞だけの問題」でもなく、6因子の相対寄与も症例で違う——**単一機序に還元しない**姿勢で読んでください。

## 5　くすみ ―― 色素だけの話ではない

くすみは、**医学的に定義された単一の病態ではありません**。境界を持たず、明るさと透明感が落ちた状態を指す訴えで、成分に分けると4つが混ざっています。

| 成分 | 何が起きているか | どこへ |
|---|---|---|
| **びまん性のメラニン** | 慢性UVと微弱な炎症の蓄積で、境界のない色素沈着が広がる | 機序は §2・§3 と同じ |
| **角層の状態** | 角層が厚く不整だと表面での光の散乱が変わり、透明感が落ちる。乾燥も効く | → [[epidermis]] |
| **糖化（黄ぐすみ）** | AGE架橋を受けた長寿命コラーゲンが黄褐色を帯びる | → [[glycation]] |
| **血流とヘモグロビン** | うっ滞や末梢循環の低下で還元ヘモグロビンの比率が上がると、暗く見える | → [[endothelium]] |

**この4つは、狙う手段がまったく違います。** 角層由来のくすみに抗糖化を当てても動かないし、糖化由来の黄色みに角層への介入を重ねても限界があります。「くすみに効く」と言われたとき、**4つのどれを狙っているのか**が分かれば、効くはずの場面と効かない場面が分かれます。

**正確さのために2つ断っておきます。**

- **糖化とくすみの因果は、ヒトでは相関が中心です。** AGE架橋が生化学的に黄褐色を帯びることと、臨床的な「黄ぐすみ」がAGEで説明できることは、同じ強度の主張ではありません（→ [[glycation]]）。
- **くすみには確立した評価指標がありません。** 色差計や分光測色で明度・色相を測る試みはありますが、「くすみが改善した」の定義が研究間で揃っていないため、**手段どうしの比較が難しい**領域です。

![くすみを4成分に分解した図。皮膚の断面に沿って、①びまん性のメラニン（表皮）②角層の状態（厚み・不整・乾燥による光の散乱）③糖化による黄褐色化（真皮の長寿命コラーゲン）④血流と還元ヘモグロビン（真皮の血管）を層ごとに配置し、それぞれが「明るさ」「色相」のどちらに効くかを右側の2軸で示す。下段に、4成分は狙う手段が別であること、そして「くすみ」には確立した評価指標がないことを注記](figures/pigmentation_くすみの4成分.png)

## この章の到達点

1. **見えている色は出口の結果。** 効く手段を決めるのは、出口を回し続けている**上流がどの層にあるか**。
2. **日光黒子・そばかすは表皮で完結する。** 上流も出口も表皮なので、表皮に届く手段が素直に効く。**ただし遮光をやめれば同じ場所で繰り返す。**
3. **PIHの上流は色素ではなく炎症。** 熱・微小損傷 → α-MSH・PGE2・SCF・ET-1 → MC1R/c-KIT → MITF↑ → tyrosinase↑ という鎖で、**PGE2の入口は plasmin 経路**。だから予防の本体は「炎症を長引かせない」こと。**PIE（ヘモグロビン由来の赤み）とは別物。**
4. **肝斑の上流は真皮にある**——DEJ破綻・血管増生とVEGF・老化線維芽細胞のSASP・肥満細胞・エストロゲンと可視光/熱・酸化ストレスとNrf2/HO-1低下の6因子。**表皮だけを叩くと再発し、熱刺激で悪化しうる。**
5. **くすみは4成分の合算**——びまん性メラニン・角層の状態・糖化・血流。**単一の病態ではなく、確立した評価指標もない。** どれを狙っているかを分けないと、効く場面と効かない場面が判別できない。

### Evidence meter

- 日光黒子・そばかす・PIH・肝斑という**臨床的な分類**と、それぞれの主たる機序：**確立した皮膚科学**
- PIHの鎖（熱・損傷 → α-MSH/PGE2/SCF/ET-1 → MC1R/c-KIT → MITF → tyrosinase）：**確立した細胞生物学（各メディエータの相対寄与は文脈依存）**
- 肝斑の真皮軸6因子：**確立しつつある細胞生物学**（「光老化・血管を含む慢性疾患」という現代的理解）／**各因子の相対寄与はヒトで継続検証中**
- 「しみ＝表皮メラノサイト単独」「レーザーで焼けば治る（肝斑）」：**否定的**
- くすみの4成分という分け方：**整理のための枠組み**。個々の機序（メラニン・角層・糖化・ヘモグロビン）はそれぞれ確立しているが、**「くすみ」という訴えへの寄与度はヒトで定量されていない**
- 糖化と臨床的な「黄ぐすみ」の因果：**相関中心。未確立**
