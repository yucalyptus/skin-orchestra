> [[atp]]で見た三大栄養素——糖質・脂質・タンパク質——のうち、この章は**脂質**が acetyl-CoA になるまでを扱います。
>
> **この章の前提**：glucose から電子を取り出す流れ（→ [[glycolysis]]）。ここで取り出した acetyl-CoA の合流先は [[tca-cycle]]です。

## この章の一言

> 脂肪をエネルギーに使うまでには、**① 脂肪細胞から脂肪酸を取り出す ② 血中を運ぶ ③ ミトコンドリアに運び込む ④ 端から炭素2個ずつ切り出して acetyl-CoA にする**の4段階があります。できた acetyl-CoA は [[tca-cycle]]へ、同時に出る **NADH と FADH₂** は電子伝達系へ回り、**ATP ができるのはその先**です（→ [[electron-transport]]）。
>
> **4段階のうち律速は③、ミトコンドリアの膜です。**細胞質にあるあいだ、脂肪酸は分解されません。そのままでは膜を通れないので、**carnitine と結合した形にしてはじめて中に入れます**。分解が始まるのは、入ってからです。

## 1　脂肪をエネルギーに使うまでの4段階

**この形のままでは、細胞の外に出ません。**血中を運ばれるのも、ミトコンドリアで分解されるのも、切り離したあとの脂肪酸です。だから最初にやることは、**3本を外すこと**になります。

::: note ちなみに ―― 脂肪酸は鎖の長さで呼び分ける

| | 炭素数 | 例 |
|---|---|---|
| **短鎖** | 6個以下 | 酢酸・酪酸（腸内細菌が作る） |
| **中鎖** | 8〜12個 | MCT オイルの成分（→ §3） |
| **長鎖** | 14個以上 | palmitate（16個）、oleate（18個）。**貯蔵されている中性脂肪も食事の脂質も、大半はこれ** |

区切りの数字は資料によって多少ずれます。**この章で「脂肪酸」と書いているのは長鎖脂肪酸**のことです。
:::

段階ごとに、**場所も、起きることも違います。**

| 段階 | どこで | 何が起きるか |
|---|---|---|
| **① 取り出す** | 脂肪細胞の脂肪滴 | 中性脂肪が **lipase** に切られ、**脂肪酸3本と glycerol** になる（**lipolysis** → §2） |
| **② 運ぶ** | 血中 | 脂肪酸は水に溶けないので **albumin に結合**して運ばれ、**CD36** などを介して細胞に入る |
| **③ 運び込む** | ミトコンドリアの膜 | **carnitine と結合した形にして膜を通す。通れるかどうかがここで決まる**（→ §3） |
| **④ 分解する** | マトリックス | 炭素2個ずつ切り出して **acetyl-CoA・NADH・FADH₂** にする（**β酸化** → §4） |

::: note ちなみに ―― エネルギー源の貯蔵の形は glycogen と中性脂肪。その中でも中性脂肪が大半

| | 中性脂肪 | glycogen |
|---|---|---|
| **量** | 蓄えの大半。glycogen の数十倍 | 肝と筋で約500 g（2,000 kcal 前後） |
| **強み** | 同じ重さで倍以上（9 対 4 kcal/g）。水を伴わないので軽い | 動員が速い。**酸素がなくても使える**。肝のものは**血糖として出せる** |
| **担当** | 長期の貯蔵 | 速さと血糖の維持 |

**酸素が追いつかず解糖系だけで ATP を作る場面**（激しい運動時の筋など）と、**血糖が下がったとき**。この2つは中性脂肪では間に合いません。だから glycogen も持っています。
:::

中性脂肪から脂肪酸を外すのは **lipase** です。3本を1本ずつ外し、あとに glycerol が残ります。

切り離された **glycerol** は、脂肪酸とは別の道を行きます。肝へ運ばれます。**中性脂肪1分子のうち、糖になって解糖系に入るのは、この部分だけ**です（→ [[glycolysis]]）。

この lipase は **hormone-sensitive lipase（ホルモン感受性リパーゼ）** と呼ばれ、**adrenaline・glucagon・ACTH・TSH・成長ホルモン**が活性化し、**insulin が阻害します。**

活性化するホルモンは、いずれも細胞内の **cAMP** を上げます。cAMP が上がると **PKA** が働き、脂肪滴の表面を覆う **perilipin-1** をリン酸化します。**リン酸化された perilipin-1 は形を変え、それまで塞いでいた脂肪滴の表面を lipase に明け渡します。**

**insulin は、この流れを止めます。**phosphodiesterase を活性化して cAMP を分解するので、PKA が働かず、perilipin-1 はリン酸化されません。食後に lipolysis が止まるのはこのためです。

さらに insulin は、**切り出された脂肪酸を、脂肪細胞を出る前に中性脂肪へ戻します**（**re-esterification**）。**分解を止めるだけでなく、戻す側にも働く**——insulin が効いていると脂肪が減りにくいのは、このためです。

**絶食中は insulin が低いので、中性脂肪は脂肪酸に分解され、中性脂肪への戻りも抑えられます。**lipolysis が続いた先で、**ケトン体**が作られます（→ §5）。

::: note ちなみに ―― 余った糖は、脂肪酸として貯蔵される
食後に glucose が入り、まず使う分と glycogen に蓄える分を超えて炭素が供給されると、流れは脂肪酸を作る側へ向かいます。これが **de novo lipogenesis（DNL、脂肪酸新生）**です。

> glucose → pyruvate → acetyl-CoA → citrate → 細胞質の acetyl-CoA → malonyl-CoA → palmitate

糖からできた pyruvate はミトコンドリアで acetyl-CoA になります。ただし acetyl-CoA 自体は内膜を越えられないため、いったん **citrate** にして細胞質へ出し、**ATP-citrate lyase（ACLY）**が acetyl-CoA に戻します。次に **acetyl-CoA carboxylase（ACC）**が **malonyl-CoA** を作り、**fatty acid synthase（FASN）**が acetyl-CoA・malonyl-CoA と **NADPH** を使って、まず palmitate を組み立てます。NADPH の供給元の一つが、解糖系の G6P から分かれる PPP です（→ [[glycolysis]]§4）。

できた脂肪酸は、glucose から作れる **glycerol-3-phosphate** に3本つながり、中性脂肪として肝や脂肪組織に貯蔵されます。つまり糖はそのまま脂肪滴へ入るのではなく、**糖の炭素から脂肪酸と glycerol 骨格の両方を作って貯蔵形にする**わけです。

ここでできる malonyl-CoA は、次節の **CPT1 を抑えます**。脂肪酸を作っている食後にはミトコンドリアへの入口を閉じ、同じ脂肪酸をすぐβ酸化しない——**合成と分解を同時に進めないための切り替え**です。ただし「食べた糖がすべて直ちに脂肪になる」という意味ではありません。まず消費と glycogen への貯蔵があり、DNL が大きくなるのは、それを超えるエネルギー供給が続く場面です。
:::

**貯蔵されている中性脂肪は、ほとんどが長鎖脂肪酸でできています。**そして長鎖脂肪酸は、細胞に届いても**そのままではミトコンドリアの膜を通れません。**そこで **carnitine** という小さな分子を付けた形（**acylcarnitine**）にして通します。マトリックスに入ると carnitine は外れて細胞質へ戻り、脂肪酸はそこから分解にかかります。

通す酵素は **CPT1** です。**脂肪酸が分解されるかどうかは、この CPT1 を通れるかどうかで決まります。**脂肪酸ができても、細胞に届いても、ここを通らなければ何も始まりません。**脂肪酸の分解の速さは、ここで決まります（律速）。**

**CPT1 を抑えているのは、脂肪酸を作る側の産物です。**脂肪酸を合成しはじめると **malonyl-CoA** ができ、これが CPT1 を抑えます。作っている最中に、同じものを分解しないための仕組みです。

> **切り分け。**「carnitine が欠ければ長鎖脂肪酸は入れない」は確立した生化学です。ただし**「足りている人が足せば分解が増える」は、そこからは導けません。**CPT1 がどれだけ働くかを決めているのは、carnitine の量ではないからです（→ 巻頭「本教材が守る切り分け」）。

::: column MCT（中鎖脂肪酸）はなぜ「すぐエネルギーになる」のか
ここまで見てきた長鎖脂肪酸は、炭素16〜18個です。**MCT は medium-chain triglyceride の略で、炭素8〜12個の中鎖脂肪酸でできた中性脂肪**——鎖が短いぶん、通る道が変わります。

長鎖脂肪酸がミトコンドリアに入るには、**carnitine を付けてもらい、CPT1 という1か所の通り道を通る**しかありません。**中鎖脂肪酸には、この手続きが要りません。**短いので、carnitine なしで膜を越えられます。

届くまでの道も違います。長鎖脂肪酸はカイロミクロンに載ってリンパを回ってから血中に入りますが、**中鎖脂肪酸は門脈からまっすぐ肝へ**行きます。

**肝に速く着いて、着いたらそのままミトコンドリアに入れる。**MCT オイルが注目されるのは、この2つが重なって**すぐエネルギーになる**からです。肝に届いた分はケトン体にも回りやすく、ketogenic diet で使われるのもここに由来します。

**ただしこれは、口から入れた MCT の話です。**貯蔵されている中性脂肪は**長鎖脂肪酸**でできています。MCT を摂ったからといって、そちらが分解されやすくなるわけではありません。**貯蔵された中性脂肪を使うときは、これまでどおり carnitine の入口を通ります。**
:::

## 5　acetyl-CoA が余るとき ―― ケトン体

**脳は普段、glucose をほぼ唯一の燃料にしています**（成人で1日およそ120 g）。脂肪酸は albumin に結合していて血液脳関門を越えられず、脳自身にも脂肪酸をエネルギーに変える力が乏しいので、脳では使えません。**そのため、絶食中でも肝は糖新生で glucose を作り続けます。**

絶食が続くと、lipolysis が進んで**肝に大量の脂肪酸が届きます。**ところが同じ肝では、糖新生が **oxaloacetate** を材料として使っています。

oxaloacetate は、**TCA回路をまわっている中間体のひとつ**です。糖新生はこれを**TCA回路から抜き取って glucose に変えます**。そのぶん、TCA回路をまわる oxaloacetate は減ります。

acetyl-CoA は、**oxaloacetate と結びついて citrate になることで TCA回路に入ります**（→ [[tca-cycle]]）。**だから oxaloacetate が減れば、acetyl-CoA は TCA回路に入れません。**行き場を失った acetyl-CoA は、肝のミトコンドリアで **HMG-CoA** を経て**ケトン体**に変えられます。

**ケトン体というのは、次の3つをまとめた呼び名**です。

- **acetoacetate**（アセト酢酸）… 最初にできるもの
- **β-hydroxybutyrate**（β-ヒドロキシ酪酸）… acetoacetate が還元された形。**血中で測るのは主にこれ**
- **acetone**（アセトン）… acetoacetate から自然にできる。呼気に出る

## この章の到達点

1. **脂肪をエネルギーに使うまでは、4段階に分かれる。**中性脂肪から脂肪酸を取り出す → 血中を運ぶ → ミトコンドリアに運び込む → acetyl-CoA に分解する。
2. **中性脂肪を分解するのは hormone-sensitive lipase で、その活性はホルモンが決めている。**adrenaline などが cAMP を上げて働かせ、**insulin は分解を止めるうえに、脂肪酸を中性脂肪へ戻す**。insulin が効いていると脂肪が減りにくいのは、このため。
3. **律速は3段階目、ミトコンドリアのマトリックスへの運び込み。**脂肪酸はそのままでは膜を通れず、**carnitine を付けた形にしてはじめて入れる**（**CPT1**）。
4. **β酸化は、端から炭素2個ずつ切り出して acetyl-CoA にする。**同時に NADH と FADH₂ が出る。**β酸化そのものは ATP を作らない**——ATP ができるのは、その先の TCA回路と電子伝達系。
5. **絶食では糖新生が oxaloacetate を TCA回路から抜くので、acetyl-CoA は TCA回路に入れずケトン体になる。**肝は作るだけで使えず、脳を含む他の組織が燃料にする。**脳では glucose の代わりになるが、glucose の需要がゼロになるわけではない。**

> [[tca-cycle]]では、糖から来た pyruvate と脂肪酸から来た acetyl-CoA が**合流したあと**を見ます。入口の作りはまったく違いますが、そこから先は同じ TCA回路です。
