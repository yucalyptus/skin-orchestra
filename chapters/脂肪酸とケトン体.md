人は、常に食事を摂っているわけではありません。それでも細胞は、食事の合間や眠っている間もATPを必要とします。そのエネルギー源になるのが、体に蓄えた糖や脂肪です。

**脂肪は、少ない重さで多くのエネルギーを蓄えられる貯蔵形です。**脂肪組織では中性脂肪として蓄えられ、必要に応じて脂肪酸を切り出し、筋や肝などの燃料にします。脂肪酸は食事の脂肪からも供給されますが、この章では、まず**体に蓄えた脂肪を取り出し、ATP産生に使うまで**を追います。

## この章の一言

**脂肪酸は、運ばれた先のミトコンドリアで acetyl-CoA に分解され、ATP の産生につながります。** 脂肪滴から取り出すこと、血中を運ぶこと、ミトコンドリアで使うことを順に追います。絶食が続くと、肝は脂肪酸からケトン体を作り、他の組織にも燃料を供給します。

## 1　全体像：脂肪をエネルギーに使うまでの4段階

貯蔵されている脂肪は**中性脂肪（トリグリセリド）**です。glycerol（グリセロール）1個に、脂肪酸が3本エステル結合でつながった形です。脂肪細胞では、これを**脂肪滴**に蓄えています。

![中性脂肪はglycerolと3本の脂肪酸がエステル結合した構造。青で示したO–Cの結合の加水分解によって脂肪酸が外れる。Rは炭化水素鎖の省略記号で、3本が同じ脂肪酸とは限らない。](figures/fatty-acid-oxidation_中性脂肪の構造.svg)

脂肪組織から燃料を供給するときは、この結合を切って脂肪酸を外します。**脂肪酸として切り出してから、血中へ放出し、利用する細胞へ届けます。**

::: note ちなみに ―― 脂肪酸は鎖の長さで呼び分ける

| | 炭素数 | 例 |
|---|---|---|
| **短鎖** | 6個以下 | 酢酸・酪酸（腸内細菌が作る） |
| **中鎖** | 8〜12個 | MCT オイルの成分（→ §4） |
| **長鎖** | 14個以上 | palmitate（16個）、oleate（18個）。**貯蔵されている中性脂肪も食事の脂質も、大半はこれ** |

区切りの数字は資料によって多少ずれます。**この章で「脂肪酸」と書いているのは長鎖脂肪酸**のことです。
:::

脂肪をエネルギーに使うまでには、**取り出す・運ぶ・運び込む・分解する**の4段階があります。まず図で、どこで何をするかを見渡します。各段階を担う酵素は、その段階の説明で紹介します。

![脂肪滴からの切り出し、血中の輸送、ミトコンドリアへの輸送、β酸化の4段階。元に戻して貯蔵する経路もあるため、切り出した量がそのまま消費量になるわけではない。](figures/fatty-acid-oxidation_4段階の整理.svg)

**脂肪細胞で脂肪酸を取り出すことと、筋や肝の細胞で脂肪酸を分解して使うことは、別の段階です。**この章では、脂肪組織から他の組織へ燃料を届ける流れを追います。

::: note 脂肪と glycogen は、貯蔵の役割が違う

| | 中性脂肪 | glycogen |
|---|---|---|
| **量** | 蓄えの大半。glycogen の数十倍 | 肝と筋で約500 g（2,000 kcal 前後） |
| **強み** | 同じ重さで倍以上（9 対 4 kcal/g）。水を伴わないので軽い | 動員が速い。**酸素がなくても使える**。肝のものは**血糖として出せる** |
| **担当** | 長期の貯蔵 | 速さと血糖の維持 |

筋の glycogen は、激しい運動時などに解糖系へ速やかに glucose を供給します。肝の glycogen は血糖の維持に使われます。**大量に蓄える中性脂肪と、速く動員する glycogen を使い分けています。**
:::

## 2　第1段階：脂肪細胞から脂肪酸を取り出す

![上段はホルモンで調節される脂肪滴での分解、下段はATGL・HSL・MGLが脂肪酸を1本ずつ外す過程。DAGとMAGは脂肪酸がそれぞれ2本・1本残った形。構造は炭素骨格と脂肪酸部分だけを示す。](figures/fatty-acid-oxidation_脂肪分解の分担.svg)

### 三つの lipase が、脂肪酸を1本ずつ外す

中性脂肪から脂肪酸を外す反応を **lipolysis（脂肪分解）** と呼びます。これを担う酵素が **lipase（リパーゼ）** です。 主な担当は次のとおりです（PMID 15550674、PMID 17074755）。

| 酵素 | 主に担う反応 |
|---|---|
| **ATGL（adipose triglyceride lipase）** | 中性脂肪から脂肪酸を1本外し、diacylglycerol（DAG：脂肪酸が2本残った形）にする |
| **HSL（hormone-sensitive lipase）** | diacylglycerol からもう1本外し、monoacylglycerol（MAG：脂肪酸が1本残った形）にする |
| **MGL（monoacylglycerol lipase）** | 最後の1本を外し、glycerol にする |

脂肪酸を3本外すと、glycerolも残ります。**glycerolは主に肝へ運ばれ、糖新生や解糖系につながる中間体へ変えられます**（→ [[glycolysis]]）。

### 食後は蓄え、食事の合間や運動中には取り出す

食後に栄養素が入ってくると、**insulin（インスリン）が増え、脂肪細胞から脂肪酸を取り出す反応を抑えます。**脂肪酸を中性脂肪として蓄える反応も促されます。

食事の間隔が空くとinsulinが低下し、その抑制が弱まります。すると、**蓄えた中性脂肪から脂肪酸を取り出し、筋や肝などへ燃料を供給しやすくなります。**

運動中には、adrenaline（アドレナリン）などの**catecholamine（カテコールアミン）**も脂肪分解を促します。筋がエネルギーを使うときに、脂肪組織から燃料を送り出す調節です（Enevoldsen et al., *J Physiol* 2004. [原著論文](https://pmc.ncbi.nlm.nih.gov/articles/PMC1665376/)）。

切り出された脂肪酸の一部は、再び中性脂肪に組み込まれます。この**re-esterification（再エステル化）**も並行して進み、血中へ出る脂肪酸の量が調節されます。

::: note もう少し詳しく ―― ホルモンの信号が脂肪滴へ届く仕組み

catecholamine がβアドレナリン受容体に結合すると、細胞内で情報を伝える **cAMP（cyclic AMP）** が増え、**PKA（protein kinase A）** が働きます。PKA は HSL と、脂肪滴の表面を覆う **perilipin-1** をリン酸化します。

これにより HSL が脂肪滴に移動し、ATGL の活性化を助ける仕組みも働いて、脂肪酸の切り出しが進みます。insulin は **phosphodiesterase** を介して cAMP の分解を促すことなどにより、この流れを抑えます。
:::


## 3　第2段階：血中を運び、筋や肝などへ届ける

脂肪細胞から放出された脂肪酸は、血液中では**albumin（アルブミン）に結合して運ばれます。**筋や肝などの細胞が、この脂肪酸を取り込んで使います。

ここまでは、脂肪組織から利用する組織へ届ける過程です。**取り込んだ細胞でATP産生に使うには、さらにミトコンドリアへ運ぶ必要があります。**

## 4　第3段階：ミトコンドリア内膜を越えて運び込む

細胞に取り込まれた長鎖脂肪酸は、**CoA（補酵素A）**と結びついた**acyl-CoA（アシルCoA）**になります。β酸化に使うには、ここからミトコンドリアの内膜を越える必要があります。

そこで、**脂肪酸部分を一時的にcarnitine（カルニチン）へ付け替えて運びます。**内膜の内側へ届いたら、脂肪酸部分を再びCoAへ戻し、β酸化へ渡します。この受け渡しが**carnitine shuttle（カルニチンシャトル）**です。

carnitineは外側へ戻り、繰り返し使われます。

::: note もう少し詳しく ―― 付け替える酵素と、膜を越える輸送体

脂肪酸部分をcarnitineへ付けるのがCPT1、膜を越えて運ぶのがCACT、内側でCoAへ戻すのがCPT2です。

![CPT1がacylcarnitineを作り、CACTが内膜を越えて運び、CPT2がacyl-CoAへ戻す。破線は外膜通過の細部を省略した輸送と、carnitineの戻り経路。タンパク質・膜の形と大きさは模式的に示す。](figures/fatty-acid-oxidation_carnitine-shuttle.svg)

| 担当 | 場所 | 役割 |
|---|---|---|
| **CPT1**（carnitine palmitoyltransferase 1） | 外膜の細胞質側 | acyl-CoA の脂肪酸部分を carnitine へ移し、**acylcarnitine** にする酵素 |
| **CACT（carnitine–acylcarnitine translocase）** | 内膜 | acylcarnitine をマトリックスへ運び、carnitine を外へ戻す輸送体 |
| **CPT2**（carnitine palmitoyltransferase 2） | 内膜のマトリックス側 | 脂肪酸部分を CoA へ戻し、β酸化に使う **acyl-CoA** にする酵素 |
:::

::: column バターコーヒーやMCTオイルは、なぜ注目されるのか

バターコーヒーやココナッツオイル、MCTオイルは、糖質を控える食事やケトン体の話でよく登場します。このコラムでは、その中でも**中鎖脂肪酸が速やかに燃料として使われる理由**を見ていきます。

**MCT（medium-chain triglyceride、中鎖脂肪酸からなる中性脂肪）オイル**は、ココナッツオイルやパーム核油から中鎖脂肪酸を取り出し、グリセロールに結合させて作ります。C8（カプリル酸）・C10（カプリン酸）を中心にしたものが一般的です（[製造元による原料・製法の説明](https://go.stepan.com/neobee)）。

MCTの消化で生じるC8・C10は、腸で吸収され、主に門脈を通って肝へ届きます。ここで重要なのが、**長鎖脂肪酸に必要なcarnitine shuttleを経ずに、ミトコンドリアでβ酸化に使われる**点です。この性質が速やかな燃料利用につながり、β酸化で生じたacetyl-CoAはケトン体の材料にもなります。

一緒に話題になる油でも、含まれる脂肪酸は異なります。

- **MCTオイル**：C8（カプリル酸）・C10（カプリン酸）を中心にした製品が多く、その比率は製品によって異なります。
- **ココナッツオイル**：C12（ラウリン酸）が多い油です。C8・C10も含みますが、C12は輸送や代謝で長鎖脂肪酸に近い性質も持ちます。
- **バター**：乳脂肪で、さまざまな長さの脂肪酸を含みます。MCTオイルを加えたバターコーヒーでは、そのMCTも燃料として供給されます。

ヒトで油を比較した試験でも、**C8を多く含む油の方が、ココナッツオイルより血中ケトン体を増やしました**（Vandenberghe et al., *Curr Dev Nutr* 2017. PMID 29955698）。コーヒーにC8・C10やココナッツオイルを加えて比較した小規模試験もあります（Baumeister et al., *J Nutr Metab* 2021. PMID 34221499）。

この話で速やかに使われるのは、**飲み物に加えて摂取した脂肪**です。体に蓄えた脂肪を取り出して使う流れは、この章で追っている4段階につながります。
:::


## 5　第4段階：β酸化で炭素2個ずつ切り出す

ミトコンドリアの内側（マトリックス）に届いたacyl-CoAの脂肪酸部分は、**端から炭素2個ずつ切り出されます**。これが **β酸化** です。外れた2個は **acetyl-CoA** になり、残った鎖は2個ぶん短くなって、この作業を繰り返します。

![palmitate由来の炭素16個のacyl-CoAを例に、β酸化で短くなる炭素鎖を示す。通常の回転ではacetyl-CoAが1個、最後の炭素4個からは2個生じる。青は各段階で切り出す側の炭素2個。各回転は4つの酵素反応からなり、中間体と反応の収支は省略。](figures/fatty-acid-oxidation_β酸化と炭素数.svg)

β酸化は、**TCA回路へ渡す acetyl-CoA と、電子伝達系へ渡す電子を取り出す過程**です。脂肪酸から取り出した電子は、NAD⁺ と FAD が受け取って **NADH・FADH₂** になります。

acetyl-CoA は [[tca-cycle]]へ進み、NADH・FADH₂ の電子は [[electron-transport]]へ渡されます。**ATP の産生は、その先の代謝につながっています。**

## 6　食事が取れない時間が続くと、ケトン体を燃料にする

食事から糖が入ってこない間、筋や肝などは、蓄えた脂肪から取り出した脂肪酸を使えます。一方、**脳は普段、主にglucose（ブドウ糖）を燃料にしており、長鎖脂肪酸を主な燃料にはしていません。**

そこで役立つのが、**肝で脂肪酸から作られる燃料、ケトン体**です。血液に乗って脳や筋などへ届き、そこでATPを作るために使われます。絶食が続くと、肝でのケトン体の産生と、脳での利用が増えます。

![肝はケトン体を作り、血中へ放出する。他の組織はacetyl-CoAへ戻して使い、脳でも絶食時の燃料になる。](figures/fatty-acid-oxidation_ケトン体の供給.svg)

**脂肪を、脳でも使える燃料に変えて届ける**のが、ケトン体を作る意義の一つです。脳はglucoseも引き続き使うため、体内でglucoseを作る**糖新生**も続きます。

### 肝で作り、受け取った細胞でATP産生に使う

肝では、β酸化で脂肪酸からacetyl-CoAを取り出し、その一部からケトン体を作ります。ケトン体を受け取った脳・心筋・骨格筋・腎などの細胞は、**acetyl-CoAに戻して、TCA回路と電子伝達系でのATP産生につなげます。**

ケトン体には、次の3種類があります。

- **acetoacetate（アセト酢酸）**：最初に作られるケトン体で、燃料として使われます。
- **β-hydroxybutyrate（β-ヒドロキシ酪酸）**：アセト酢酸が還元された形で、これも燃料になります。血中ケトン体の測定でよく使われる指標です。
- **acetone（アセトン）**：アセト酢酸から自然に生じ、呼気へ出ます。

::: note もう少し詳しく ―― 絶食でケトン体が増える仕組み

acetyl-CoAをTCA回路で使うには、まず**oxaloacetate（オキサロ酢酸）と結合して、citrate（クエン酸）になる**必要があります。

絶食が続くと、肝では次の二つの変化が起こります。

- 脂肪組織から届く脂肪酸が増え、β酸化で**acetyl-CoAが多く作られます。**
- 血糖を保つために糖新生が進み、**oxaloacetateがglucoseを作る材料にも使われます。**

このため、増えたacetyl-CoAをすべてTCA回路で使うことが難しくなります。肝は、**そのacetyl-CoAを材料にケトン体を作り、他の組織へ送り出します。**

![絶食時にはacetyl-CoAの供給が増え、oxaloacetateは糖新生にも使われる。TCA回路への入口と、HMG-CoAを経てケトン体を作る経路を示す。中間反応・補酵素・細胞内区画は省略している。](figures/fatty-acid-oxidation_ケトン体への分岐.svg)

肝自身には、ケトン体の利用に必要な酵素**SCOT**がないため、作ったケトン体は他の組織へ供給します。長期絶食のヒト研究では、脳が使うエネルギーの約2/3をケトン体が担いました（PMID 6061736）。
:::



## 7　使いきれない糖を、脂肪にして蓄える

糖は、すぐにエネルギーとして使うほか、**glycogen（グリコーゲン）や脂肪にして蓄える**こともできます。必要なエネルギーを超えて糖が供給され続けると、脂肪酸を作る材料としても使われます。この脂肪酸を新しく作る反応が、**de novo lipogenesis（DNL、脂肪酸新生）**です。

### 糖を分解して得た材料から、脂肪酸を組み立てる

ここまで見てきたように、糖を分解すると**acetyl-CoA（アセチルCoA）**ができます。これはATP産生に使うだけでなく、**脂肪酸を作る材料にもなります。**細胞は、その炭素をつなぎ合わせて、脂肪酸の長い鎖を作ります。

できた脂肪酸をグリセロールの骨格に3本結びつけると、この章の最初に出てきた**中性脂肪**になります。中性脂肪は脂肪滴に蓄えられ、必要なときには再び脂肪酸を取り出して使えます。

::: note もう少し詳しく ―― 脂肪酸を作る場所と酵素

**脂肪酸を組み立てる場所は、細胞質です。**糖からできたpyruvate（ピルビン酸）は、ミトコンドリアでacetyl-CoAになります。その炭素を細胞質へ運ぶために、いったん**citrate（クエン酸）**にしてミトコンドリアの外へ出します。

細胞質では、次の酵素が順に働きます。

- **ACLY（ATP-citrate lyase）**：citrateから、材料となるacetyl-CoAを取り出します。
- **ACC（acetyl-CoA carboxylase）**：acetyl-CoAを、鎖を伸ばす材料の**malonyl-CoA（マロニルCoA）**に変えます。
- **FASN（fatty acid synthase）**：acetyl-CoAとmalonyl-CoAを使い、炭素16個の脂肪酸、**palmitate（パルミチン酸）**を作ります。

![解糖系でできたpyruvateはミトコンドリアへ入り、acetyl-CoA、citrateへ変わる。citrateとして細胞質へ出て、ACLYがacetyl-CoAを、ACCがmalonyl-CoAを作り、FASNがpalmitateを合成する。図は炭素の主な流れで、oxaloacetate、ATP・CoA・NADPHなどの補基質と併産物は省略。](figures/fatty-acid-oxidation_糖から脂肪酸を作る.svg)

この合成には、**NADPH**から電子を受け取る必要があります。NADPHの供給元の一つが、解糖系から分かれる**pentose phosphate pathway（PPP、ペントースリン酸経路）**です（→ [[glycolysis]]）。また、糖からは中性脂肪のグリセロール骨格になる**glycerol-3-phosphate（グリセロール3-リン酸）**も作れます。

合成途中にできるmalonyl-CoAは、長鎖脂肪酸をミトコンドリアへ運ぶ**CPT1**を抑えます。これにより、脂肪酸を作っているときには、β酸化に使うための取り込みが抑えられます。
:::


## この章の到達点

1. **脂肪細胞で取り出し、血中で運び、利用する細胞のミトコンドリアへ入れ、β酸化で分解する。**場所と役割の異なる4段階がつながります。
2. **脂肪滴の分解は ATGL・HSL・MGL が分担する。** catecholamine は放出を促し、insulin は分解を抑える。切り出した脂肪酸の一部は中性脂肪へ戻る。
3. **長鎖脂肪酸を内膜の内側へ届けるのが carnitine shuttle。** CPT1 が運べる形に変え、CACT が内膜を越えて運び、CPT2 が acyl-CoA に戻す。
4. **β酸化は、TCA回路へ acetyl-CoA を、電子伝達系へ電子を渡す過程。** NADH・FADH₂ が電子を受け取り、その先で ATP の産生につながる。
5. **絶食では脂肪酸の供給が増え、肝で acetyl-CoA がケトン体へ回りやすくなる。**肝は作るだけで使えず、脳を含む他の組織が燃料にする。**脳では glucose の代わりになるが、glucose の需要がゼロになるわけではない。**

[[tca-cycle]]では、糖からも脂肪酸からも生じる **acetyl-CoA が合流したあと**を見ます。
