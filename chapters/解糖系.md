細胞は、取り込んだ **glucose（グルコース、ブドウ糖）**を分解してATPを作ります。その最初の工程が、細胞質で進む解糖系です。糖を分解する途中には、細胞を作る材料へつながる分岐もあります。

## この章の一言

> **解糖系は、glucoseをpyruvate（ピルビン酸）へ分解し、少量のATPを作る経路です。**pyruvateはミトコンドリアでさらに利用されるほか、lactate（乳酸）にもなります。解糖系の途中からは、核酸や脂質などを作るための材料も供給されます。

## 1　解糖系は、何を受け取り、何を作るのか

解糖系では、**glucose 1分子からpyruvate 2分子**ができます。前半でATPを2個使い、後半で4個作るため、差し引き **2 ATP**が得られます。

この過程で、糖から取り出した電子を受け取るのが **NAD⁺**です。電子を受け取ると **NADH**に変わります。glucose 1分子からは、NADHも2分子できます（→ [[nad]]）。

![glucoseの炭素6個が3個ずつの2分子へ分かれ、pyruvate 2分子になる。ATP・NADHはglucose 1分子分の収支。](figures/glycolysis_炭素の分割とATP.svg)

炭素6個の糖が途中で炭素3個の分子二つに分かれるため、後半は2分子分の反応が進みます。**前半でATPを使い、後半で回収する流れ**を、炭素の分かれ方と合わせて見てください。

::: note もう少し詳しく ―― なぜ後半は2分子分なのか
炭素6個のfructose-1,6-bisphosphateが、**glyceraldehyde-3-phosphate（GAP）**と **dihydroxyacetone phosphate（DHAP）**に分かれます。triose phosphate isomerase（TPI）がDHAPをGAPへ変換するため、後半はGAP 2分子から進みます。次の詳細図は上から下へ読みます。「2×」は後半が2分子分進むことを示します。2-phosphoglycerateなど一部の中間体・酵素名を省略しています。

![解糖系の主経路とATPの投資・回収。左の帯がATPを使う区間と作る区間、右が主な調節点。](figures/glycolysis_ATP投資と回収.svg)
:::

::: reaction 解糖系の収支（主な生成物）
glucose → 2 pyruvate ＋ 正味 2 ATP ＋ 2 NADH
:::

### pyruvateと電子を、ミトコンドリアへ渡す

pyruvateをさらに酸化するときは、ミトコンドリアへ入ります。NADHが持つ電子も、**shuttle（シャトル）**という仕組みでミトコンドリア側へ渡されます。shuttleは電子を受け渡す複数の反応を組み合わせたもので、NADH分子そのものが内膜を通るわけではありません。

glucose 1分子をTCA回路・電子伝達系まで利用すると、解糖系の分も含めて約30〜32 ATPを得られます。解糖系はこの一連の代謝の入口です（→ [[tca-cycle]]・[[electron-transport]]）。

## 2　流れを調節する、不可逆な3段階

解糖系には、細胞内で逆向きにほとんど進まない **不可逆な反応が3段階**あります。hexokinase・phosphofructokinase-1（PFK-1）・pyruvate kinaseが担います。**これらは解糖系の流れを調節する重要な場所**で、酵素の働きが変わると、糖を分解する速さも変わります（Tanner et al., *Cell Syst* 2018. [原著論文](https://pmc.ncbi.nlm.nih.gov/articles/PMC6062487/)）。

### 入口：hexokinaseが糖にリン酸を付ける

glucoseは、輸送体 **GLUT**を通って細胞へ入ります。**hexokinase**がATPを1個使ってリン酸を付けると、**glucose-6-phosphate（G6P）**になります。

G6PはGLUTを通れないため、細胞内にとどまって代謝に使われます。入口で使うATPには、**取り込んだ糖を細胞内の代謝へ渡す役割**があります。

::: note ちなみに ―― FDG-PET が見ているのは、この段です
FDG は glucose の類似体で、GLUT で取り込まれ hexokinase でリン酸化されますが、その先へは代謝されません。**リン酸化されて外へ戻れなくなったまま細胞内に溜まる**（metabolic trapping）ので、集積として写ります。

多くのがん細胞では、酸素があっても解糖系に寄る **Warburg 効果**に伴って、glucose の取り込みとリン酸化が盛んになります。そのため FDG も多く取り込まれ、**FDG-PET の高集積として見える**わけです（→ §6）。ただし、FDG は炎症や感染でも集積し、がんでも種類や大きさによっては集積が弱いため、**高集積だけでがんと確定する検査ではありません。**
:::

![hexokinase・PFK-1・pyruvate kinaseの反応と調節。不可逆な3段階の位置を示す。](figures/glycolysis_不可逆な3反応.svg)

### PFK-1とpyruvate kinaseが、その先の流れを調節する

- **PFK-1**：ATPやcitrateが多いと活性が下がり、AMPなどが増えると活性が上がります。エネルギー状態に応じて解糖系の流れを調節します。
- **pyruvate kinase**：最後の反応でATPを作ります。その一型である **PKM2** は、増殖する細胞などで働きます。活性の調節は、解糖系を進める量と、中間体を合成経路へ回す量に関わります。

## 3　低酸素での切り替え ―― HIF-1α

酸素が足りないと、ミトコンドリアでのATP産生を続けにくくなります。細胞は、酸素を直接使わない **解糖系の働きを増やして、ATP産生を支えます。**その切り替えに関わるのが **HIF-1α（hypoxia-inducible factor-1α）**です。

HIF-1αは低酸素で蓄積し、糖の取り込みや解糖系に関わる遺伝子の発現を促します。同時に、pyruvateがTCA回路へ進む量を減らし、lactateへ回りやすくします。これは、限られた酸素のもとで代謝を維持する適応です（PMID 16517405）。

::: note もう少し詳しく ―― HIF-1αが変える酵素
HIF-1αは、転写因子HIF-1の一部です。通常酸素下では速やかに分解されますが、低酸素では蓄積し、HIF-1βと組んで遺伝子発現を促します。

- **糖の取り込みと解糖を支える**：GLUT、解糖系酵素、乳酸を作るlactate dehydrogenase A（LDHA）などを増やします。LDHAによる反応はNAD⁺の再生にもつながります（→ §5）。
- **TCA回路へ進む量を減らす**：PDH kinase 1（PDK1）を増やします。PDK1は、pyruvateをacetyl-CoAへ変える酵素複合体pyruvate dehydrogenase（PDH）の活性を下げます。糖由来の電子がミトコンドリアへ入る量を抑えることで、低酸素でのROS（活性酸素）による傷害を減らす働きがあります（PMID 16517405；→ [[tca-cycle]]）。
:::

## 4　炭素の三つの行き先

取り込んだglucoseは、すべてがATP産生へ進むわけではありません。一部は **ペントースリン酸経路（pentose phosphate pathway、PPP）**へ入り、核酸の材料や、合成・抗酸化に必要な電子の供給に使われます。

図には、二つの分岐点があります。**G6PでPPPへ分かれ、その先のpyruvateでミトコンドリアへ進む経路とlactateを作る経路に分かれます。**

![G6PからPPPへ進む分岐と、pyruvateからミトコンドリア・lactateへ進む分岐。](figures/glycolysis_炭素の分岐.svg)

### PPPは、合成材料と抗酸化に必要な還元力を作る

PPPで得られるのは、**ribose-5-phosphate（リボース5-リン酸）**と **NADPH**です。ribose-5-phosphateは核酸の材料に、NADPHは合成反応や抗酸化システムへ電子を渡す補酵素として使われます。

抗酸化では、NADPHが **glutathione（グルタチオン）**や **thioredoxin（チオレドキシン）**を還元型へ戻す反応を支えます。これにより、酸化への対処を繰り返せます。PPP自体はATPを作りませんが、**細胞を作り、酸化から守るために必要な経路**です（→ [[oxidative-stress]]）。

::: note もう少し詳しく ―― G6PDと赤血球の抗酸化
PPPの入口にある **glucose-6-phosphate dehydrogenase（G6PD）**と、その先の6-phosphogluconate dehydrogenaseがNADPHを作ります。

成熟赤血球はミトコンドリアを持たず、ATP産生を解糖系に、NADPH産生をPPPに依存します。**G6PD欠損症ではNADPHを供給する能力が低下し、酸化負荷が加わると溶血しやすくなります。**残る酵素活性は変異によって異なります（Powell et al., *Genetics* 2024. PMID 39607789）。

glutathioneはcysteineを含む3残基のペプチド、thioredoxinはSH基を持つ小さなタンパク質です。どちらも酸化還元反応で働き、NADPHの還元力によって再利用されます。
:::

## 5　NAD⁺を戻さないと解糖は止まる ―― lactate の役割

解糖系では、NAD⁺が電子を受け取ってNADHになります。**NADHから電子を渡してNAD⁺へ戻すことが、解糖系を続ける条件**です。

戻し方には、ミトコンドリアへ電子を渡す経路と、**lactate dehydrogenase（LDH）**という酵素でpyruvateへ電子を渡す経路があります。後者ではlactateができます。

![NAD⁺を再生する二つの経路。shuttleで電子を渡す経路と、LDHでpyruvateへ渡す経路。](figures/glycolysis_NAD再生の2経路.svg)

酸素が足りないと、電子伝達系へ電子を渡しにくくなるため、lactateを作る経路が重要になります。酸素があっても、解糖系の流量が大きく、shuttleやミトコンドリア側の処理が追いつかなければ、lactateへ回る量が増えます。

::: note もう少し詳しく ―― NADHとATPができる段階
解糖系の後半でNADHを作るのは、**glyceraldehyde-3-phosphate dehydrogenase（GAPDH）**の反応です。NAD⁺が不足すると、この反応が進みにくくなります。

![GAPDHはNADHを作り、直後のphosphoglycerate kinaseの反応でATPができる。](figures/glycolysis_NADHとATPの回収.svg)

GAPから取り出された電子をNAD⁺が受け取ります。同時に無機リン酸（Pi）が取り込まれ、1,3-bisphosphoglycerateができます。そのリン酸をADPへ渡す直後の反応でATPが作られます。glucose 1分子からGAPが2分子できるため、この部分で得られるのは2 NADHと2 ATPです。

TCA回路でもNAD⁺が電子を受け取ります。電子伝達系が滞ってNADHをNAD⁺へ戻しにくくなると、PDHとTCA回路の反応も進みにくくなります（→ [[tca-cycle]]）。
:::

### LDHは、lactateとpyruvateを相互に変える

**LDHは、この反応を両方向に進められる酵素です。**細胞によって、主に進む向きが変わります。

::: reaction LDHの可逆反応
 enzyme: LDH
pyruvate ＋ NADH ⇌ lactate ＋ NAD⁺
:::

- **lactateを出す細胞**：pyruvate側からlactate側へ進み、NAD⁺を戻して解糖系を続ける。
- **lactateを受け取る細胞**：lactate側からpyruvate側へ進み、TCA回路へ。肝では糖新生にも使う。

式はH⁺を省略しています。反応の向きは、pyruvate・lactate・NADH・NAD⁺の量や、その細胞で進む他の代謝反応によって変わります。

::: note LDH が多いと、lactate はたまりやすい？
**LDH が多いだけでは、lactate がたまるとは限りません。**LDH は両方向に働くため、細胞内で pyruvate と NADH が多く作られれば lactate 側を支え、反対に lactate を取り込む細胞では pyruvate へ戻す側も支えます。実際の蓄積は、**解糖系が lactate を作る速さ**と、細胞外への搬出、肝・心筋・酸化的筋線維などが**取り込んで使う速さ**のバランスで決まります。

なお、血液検査の「LDH高値」は別の話です。これは主に、肝、筋、血球などから血中へ漏れた LDH を測っており、**血中 lactate が高いことを直接示す値ではありません。**
:::

lactateは、作る細胞ではNAD⁺の再生に関わり、受け取る細胞では燃料になります。運動時の増加も酸素不足だけでは説明できず、疲労をlactate一つに結びつけることはできません。

## 6　Warburg効果 ―― 酸素があっても解糖に寄る

**酸素が十分あるのに解糖に偏り、lactate を出す。** これが Warburg 効果です。腫瘍で最初に記載されましたが、腫瘍に限りません。**活性化した免疫細胞や、増殖・遊走している線維芽細胞でも同じ寄りが報告されています。**

増殖・修復中の細胞には、**ATPと、核酸・アミノ酸・脂質の材料の両方**が必要です。糖の取り込みや解糖系の流量を増やすことは、ATPを作りながら中間体を合成へ回すことにも役立ちます。ただし、Warburg効果の成り立ちは細胞や条件によって異なり、「材料が必要だから」という一つの理由だけでは説明できません。

増殖中の細胞は **TCA回路も利用し、その中間体を脂質やアミノ酸の材料として取り出します**（→ [[tca-cycle]]）。

::: column 呼吸の進化 ―― 解糖系は酸素より古い
太古の地球に酸素はほとんどなく、生き物は酸素を使わない経路でエネルギーを得ていました。解糖系はその時代の経路のひとつで、**いまも多くの生き物が使い続けています。**

約24億年前、シアノバクテリアが酸素発生型の光合成を始め、大気の酸素が増えます。**当時の生き物にとって、O₂ は反応性の高い猛毒でした。**多くが絶滅するか、酸素の届かない場所——地中・深海・そして動物の腸の中——へ退きます。ヒトの腸内細菌に嫌気性菌が多いのは、その名残です（→ [[gut-microbiome]]）。

やがて、その酸素を電子の最後の受け取り手として使う生き物が現れます。**取り出せる ATP は桁違いに増えました**（2 対 約30〜32、§1）。大きなゲノムを持ち、動き回る多細胞生物が現れたのはそのあとです。カンブリア紀の爆発的な多様化も、酸素濃度の上昇と結びつけて語られます。

ただし、大きな代償がありました。**電子を O₂ へ流し続ける限り、一定の割合は漏れて ROS になります**（→ [[electron-transport]]）。だから酸素を使う生き物は、例外なく活性酸素を消す仕組みを持っています。細菌からヒトまで、SOD や catalase は共通です。**抗酸化は後から足したものではなく、酸素を使うための条件だった**ということです（→ [[oxidative-stress]]）。**それでも酸素を使う側が繁栄しました。**酸化のリスクを抱え込んでも、取り出せるエネルギーの差がそれを上回ったからです。
:::

## この章の到達点

1. 解糖系は酸素を直接使わず、glucose 1分子から **2 pyruvate・正味2 ATP・2 NADH**を作ります。
2. hexokinase・PFK-1・pyruvate kinaseは、不可逆な反応を担う重要な調節点です。
3. 低酸素ではHIF-1αが解糖系を支え、PDK1を介して糖由来の炭素がTCA回路へ進む量を減らします。
4. 糖の炭素は、ATP産生だけでなく、PPPなどを通じて合成材料と還元力の供給にも使われます。
5. **NAD⁺の再生が解糖系を支えます。**lactateを作る反応はその一つで、lactateは他の細胞の燃料にもなります。
6. Warburg効果は、酸素があってもlactate産生が増える現象です。増殖する細胞も、ATPと合成材料の両方を必要とします。

> [[tca-cycle]]では、ミトコンドリアへ入ったpyruvateがacetyl-CoAに変わり、エネルギー産生と材料供給につながる経路を見ます。
