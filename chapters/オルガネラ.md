> 機器や製剤の資料には「線維芽細胞を活性化してコラーゲンを増やす」と書かれています。実際には細胞の内側で、核・リボソーム・粗面ER・Golgi が順に働いてコラーゲンを1本作り、外へ出しています。この章では細胞の中に入り、その分担を思い出します。

## この章の一言

> 細胞の仕事は、単一のオルガネラでは完結しません。
>
> **分泌タンパク質を1本作って外に出す**という一つの仕事に、複数のオルガネラが順に関与します。細胞は単なる袋ではなく、**オルガネラが orchestration（連携）して産物を出す単位**です。

![1個の細胞内にnucleus、ribosome、ER、Golgi、mitochondria、lysosome、peroxisomeの7つを配置し、それぞれの本業を示す。peroxisomeはcatalaseによるH₂O₂処理と脂肪酸β酸化を担い、補助構造としてcytoskeletonとplasma membraneも示される。](figures/organelles_まず覚える7つのオルガネラ.png)

## 1　分泌タンパク質を1本、外に出すまで

コラーゲンに限らず、細胞外で働くタンパク質は、すべて同じ経路を通って外に出ます。

![分泌タンパク質collagenが外に出るまでの経路。核でmRNAを転写し、ribosomeで翻訳が始まるとN末端のsignal peptideが宛名として認識され、ribosomeがrough ER膜へ結合する。ERで折りたたみ・加工・品質管理、Golgiで仕上げ・仕分けを受け、secretory vesicleから細胞外へ分泌される。signal peptideがないタンパク質はfree ribosomeで合成され、細胞質に留まる。](figures/organelles_細胞は小さな工場.png)

**一つのオルガネラが完成させるのではなく、受け渡しで完成します。** 核がどの遺伝子をどれだけ読むかを決め、リボソームがその写し（mRNA）を読んでアミノ酸をつなぎ、粗面ERが折りたたみ、Golgiが仕分け、小胞が膜まで運ぶ。この搬送は細胞骨格のレール上で行われます。全工程がATPを消費するので、ミトコンドリアはそのあいだずっと働いています。折り損じや古い部品はリソソームが分解し、アミノ酸に戻して次の合成へ返します。

**「産生能が上がる」とは、この受け渡しのうち、いちばん遅いステップ（律速段階）が速くなることです。** 見るべきなのは、どのオルガネラかではなく、どこが詰まっているかです。

## 2　まず覚える7つのオルガネラ

オルガネラは膜で仕切られた別々の環境です。その環境の違いが、そこで何ができるかを決めています。

| オルガネラ | 何を担当するか | 押さえどころ |
|---|---|---|
| **核**（nucleus） | DNAを保管し、どの遺伝子を読むかを決める | 二重の核膜で囲まれ、**核膜孔**を介してのみ細胞質とやりとりする。**DNAの原本はここから出ない**——出ていくのはコピー（mRNA）だけ。細胞の個性はここで決まる（→ [[dna-to-protein]]・[[epigenome]]） |
| **リボソーム**（ribosome） | mRNAを読んでアミノ酸をつなぐ組み立て機 | オルガネラの中では例外的に**膜を持たない**。細胞質に浮いているものと、粗面ERの膜に貼りついているものがある。**この貼りつくかどうかが §3 の分岐点になる** |
| **粗面ER**（rough ER） | 分泌タンパク質を加工・品質管理する | リボソームが貼りついた膜の網。内部は細胞質より**酸化的**で、chaperone（折りたたみを介助する分子）がはたらき、折り損じは通さない。**分泌タンパク質はここでしか正しく折りたためない** |
| **Golgi装置** | 仕分けて送り出す | ERから届いた荷物に糖鎖などの仕上げをし、**行き先ごとに仕分ける**。細胞膜へ、リソソームへ、細胞外へ——宛先を付けて送り出す |
| **ミトコンドリア**（mitochondria） | ATPを作り、代謝も調節する | 二重膜で、内膜が大きく折れ込んで（cristae）表面積を稼ぐ。ATPを作るだけでなく、代謝物を通じて**核へ状態を報告する調節装置**。独自の小さなDNA（mtDNA）を持つ（→ 「エネルギー」・[[mito-quality-control]]） |
| **リソソーム**（lysosome） | 不要物を分解して再利用する | 内部が酸性（pH 5前後）の分解槽。古いタンパク質やオルガネラを**アミノ酸・脂肪酸・糖に戻す**。分解産物は材料として再利用される（→ [[autophagy]]） |
| **ペルオキシソーム**（peroxisome） | 脂質の代謝と酸化還元 | **catalase を大量に抱え、過酸化水素（H₂O₂）をその場で水と酸素に分解する場**。同時にミトコンドリアが苦手な**極長鎖脂肪酸のβ酸化**を担い、その反応でH₂O₂を出す——**出す場所と消す場所が同じ小器官の中**にある設計（→ [[oxidative-stress]]・[[sebum]]） |

このうち**ミトコンドリアとリソソームだけは、特定の工程を担当するのではなく、全工程で同時に働きます。** 作る仕事にはエネルギーが要り、折り損じや古い部品は片づけないと溜まります。この二つが止まると、他のオルガネラが健全でも産生は回りません。

## 3　なぜ「核→リボソーム→ER→Golgi→分泌」の順でなければならないのか

この順番は、覚えるだけの並びではありません。分岐点は、翻訳が始まった直後——**鎖の先頭に signal 配列（signal peptide）があるかどうか**です。

```flow
翻訳中の鎖に signal 配列がある → 粗面ERへ引き込まれる → ER内で折りたたみ・品質検査 → 小胞でGolgiへ → 分泌小胞 → 細胞外へ　／　signal 配列がない → 細胞質にとどまり、細胞質で働く
```

**分泌経路に入るかどうかは、あとから選ぶのではなく、設計図に書かれた"宛名"で最初から決まっています。** signal 配列がある鎖は翻訳の途中で認識され、リボソームごと粗面ERの膜に引き寄せられ、合成されながらそのままER内へ送り込まれます（co-translational translocation）。signal 配列がない鎖は細胞質で作られ、細胞質で働きます——解糖系の酵素などがこちらです。

**折りたたみは仕上げの工程ではなく、機能そのものを作る工程です。** タンパク質はアミノ酸が一列につながった鎖として作られますが、鎖のままでは働きません。酵素の活性部位も、受容体の結合部位も、鎖の上では離れた位置にあるアミノ酸が、折りたたまれて初めて一か所に集まってできます。並びが正しくても、折りたたみが違えば働きません。

折りたたみ途中の鎖は、細胞にとって危険でもあります。完成したタンパク質では内側に隠れている疎水的な部分が、途中では外に出ています。細胞の中は分子が高密度に詰まっているので、露出したままの鎖は近くの分子とくっついて凝集します。だからERは折り損じを通さず、直せない鎖は分解へ回します（ERAD, ER-associated degradation）。処理が追いつかずに折り損じが溜まった状態が ER stress で、これに対する応答（UPR）は[[autophagy]]で扱います。コラーゲンでいえば、三重らせんを組めなかった鎖は分泌されません。

ここから順番の理由が出てきます。

1. **ERを通らないと折りたためない。** ERの中は細胞質より酸化的で S–S 結合（ジスルフィド結合）が架かり、chaperone が介助し、折り損じを通さない品質管理がはたらきます。**この環境はERにしかありません。**
2. **細胞質に裸で出せない。** 折りたたみ途中の疎水的な鎖を細胞質に放り出せば、他の分子とくっついて凝集します。だから膜の中を通して運ぶ必要があります。
3. **ERを通ったあとの送り先を振り分けるのはGolgiです。** ERを出たタンパク質は Golgi で仕上げと**仕分け**を受けて初めて送り先が確定します。仕分けを経ずに分泌されることはありません。
4. **移動は小胞で、向きがある。** ER→Golgi→細胞膜の移動は小胞（vesicle）が細胞骨格のレール上を運ぶ**一方向の物流**です。だからこの順番は、そのまま**物理的な移動経路**でもあります。

## 4　実例：線維芽細胞がコラーゲンを作る

上の一般則を、この教材で最も多く扱う分泌タンパク質でたどります。

![線維芽細胞の中でコラーゲンができるまでの経路。核でCOL遺伝子を読み、リボソームで鎖を作り、粗面ERで水酸化と三重らせん形成、Golgiで梱包、分泌後に細胞外で線維へ組み上がる](figures/organelles_オルガネラ.png)

**ミトコンドリアとリソソームは、この過程のどの段階でも同時に働いています。** 水酸化にどの補因子が要るか、三重らせんがどう組まれるか、細胞外でどう架橋するかは、[[fibroblast-collagen]]で扱います。

![ミトコンドリアが供給するATPは、転写・翻訳と初期折りたたみ・Golgiでの仕上げ・分泌小胞の輸送という4か所へ同時に入る。リソソームは損傷タンパク質と古いオルガネラを分解し、アミノ酸・脂質などの小さな材料を粗面ER・Golgi・分泌小胞の側へ戻す](figures/organelles_エネルギーと掃除.png)

工程は一続きです。**どの段階が滞っても出力は落ちます。**

![上段は全段そろって出力が保たれる状態。中段は粗面ERの加工だけが滞り、手前に未完成の鎖がたまって出力が落ちる。下段はエネルギー不足で5段すべてが遅くなり、やはり出力が落ちる。律速は一か所とは限らない](figures/organelles_律速.png)

この「律速」の考え方は[[fibroblast-collagen]]で正面から扱います。

## 5　補助的に押さえる構造

主役ではありませんが、後の章で顔を出します。

| 構造 | 何をするか | 押さえどころ |
|---|---|---|
| **細胞膜** | 内と外を仕切り、物質の出入りを制御する | 通す・通さないの規則は分子の側の性質で決まる（→ [[membrane-transport]]） |
| **endosome**（エンドソーム） | 外から取り込んだものを仕分ける小胞 | 分解へ回すか、膜へ戻すかを決める（→ [[membrane-transport]]） |
| **lipid droplet**（脂肪滴） | 中性脂肪をためる小滴 | 脂肪細胞では細胞の大部分を占める主役になる（→ [[adipose]]） |
| **ECM**（細胞外マトリックス） | 細胞の"外"の足場 | 足場であると同時に、細胞に情報も伝える（→ [[ecm]]） |
| **cytoskeleton**（細胞骨格） | 形の維持・運搬・張力の感知 | **actin filament**＝膜直下で収縮し張力を生む／**microtubule**＝小胞とオルガネラを運ぶレール／**intermediate filament**＝引っ張りに耐える芯（表皮の keratin）。**integrin** で ECM に接着した点で細胞骨格を引くと、足場の硬さと張力が細胞内シグナルに変換される＝**mechanotransduction**（→ [[ecm]]） |

## この章の到達点

1. 細胞の仕事は単一のオルガネラでは完結しない。**分泌タンパク質を1本外へ出す**という一つの仕事に、核・リボソーム・粗面ER・Golgi が順に関与し、ミトコンドリアとリソソームが全工程で同時に働く。
2. 7つのオルガネラはそれぞれ別の環境を持つ（酸化的なER内、pH 5前後のリソソーム、catalase を抱えたペルオキシソーム）。担当する仕事は、その環境で何ができるかで決まっている。
3. この順番は覚えるだけの並びではない。**signal 配列で分泌経路に入るかが決まり、折りたためるのはERの中だけで、その先の送り先はGolgiの仕分けで確定する。**だからこの順番になる。**どの工程が滞っても出力は落ちる。**
4. 「産生能が上がる」とは、この受け渡しのうち**いちばん遅いステップ（律速段階）が速くなる**こと。見るべきなのは、どのオルガネラかではなく、どこが詰まっているか。

![細胞の中は連携するオルガネラでできている](figures/organelles_まとめ.png)

> [[cell-types]]では、これらのオルガネラが**独立した袋ではなく、互いに物質やシグナルを交換し合っている**ことを見ます。「ミトコンドリアを活性化する」という説明が、なぜそれだけでは足りないのかという話につながります。
