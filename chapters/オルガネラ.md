> 細胞の中には、核・ミトコンドリア・小胞体・Golgi装置など、異なる仕事を担う構造があります。これらを**オルガネラ（細胞内小器官）**と呼びます。一つの仕事を一つのオルガネラが完成させるのではなく、材料や情報を受け渡しながら進めています。この章では、分泌タンパク質が作られて細胞外へ出るまでをたどり、それぞれの役割を見ます。
>
> **先に読んでおく章**：細胞の基本構造（→ [[cell]]）

## この章の一言

> **細胞の仕事は、一つのオルガネラでは完結しません。**作る・加工する・運ぶ・エネルギーを供給する・不要なものを再利用する。複数のオルガネラが**orchestration（連携）**することで、一つの産物が完成します。

![細胞内の主なオルガネラと役割。合成・加工・輸送・エネルギー供給・分解を分担する。](figures/organelles_まず覚える7つのオルガネラ.png)

## 1　分泌タンパク質を1本、外に出すまで

コラーゲンなど、細胞外へ分泌される多くのタンパク質は、核・リボソーム・粗面ER・Golgi装置を順に経て外へ出ます。

![多くの分泌タンパク質は、signal peptideによってERへ入り、加工・品質管理を経てGolgiへ進む。ERに入らないタンパク質にも、別の移行シグナルで核やミトコンドリアへ運ばれるものがある。](figures/organelles_細胞は小さな工場.png)

**一つのオルガネラが完成させるのではなく、受け渡しで完成します。** 核がどの遺伝子をどれだけ読むかを決め、リボソームがその写し（mRNA）を読んでアミノ酸をつなぎ、粗面ERが折りたたみ、Golgiが仕分け、小胞が膜まで運ぶ。この搬送は細胞骨格のレール上で行われます。全工程がATPを消費するので、ミトコンドリアはそのあいだずっと働いています。折り損じや古い部品はリソソームが分解し、アミノ酸に戻して次の合成へ返します。

産生量は、材料の供給、合成、加工、輸送の各工程に左右されます。**全体の進み方を制限している工程を、律速段階と呼びます。** 一つのオルガネラだけでなく、どの工程が滞っているかを見る必要があります。

## 2　まず覚える7つのオルガネラ

多くのオルガネラは膜で仕切られ、異なる環境を保っています。その違いが、担当する反応を支えます。リボソームのように膜を持たない構造もあります。

| オルガネラ | 何を担当するか | 押さえどころ |
|---|---|---|
| **核**（nucleus） | DNAを保管し、どの遺伝子を読むかを決める | 二重の核膜で囲まれ、**核膜孔**を介してのみ細胞質とやりとりする。**DNAの原本はここから出ない**——出ていくのはコピー（mRNA）だけ。細胞の個性はここで決まる（→ [[dna-to-protein]]・[[epigenome]]） |
| **リボソーム**（ribosome） | mRNAを読んでアミノ酸をつなぐ組み立て機 | オルガネラの中では例外的に**膜を持たない**。細胞質に浮いているものと、粗面ERの膜に貼りついているものがある。**この貼りつくかどうかが §3 の分岐点になる** |
| **粗面ER**（rough ER） | 分泌タンパク質を加工・品質管理する | リボソームが貼りついた膜の網。内部は細胞質より**酸化的**で、chaperone（折りたたみを介助する分子）がはたらき、折り損じは通さない。多くの分泌タンパク質は、この環境で折りたたまれる |
| **Golgi装置** | 仕分けて送り出す | ERから届いた荷物に糖鎖などの仕上げをし、**行き先ごとに仕分ける**。細胞膜へ、リソソームへ、細胞外へ——宛先を付けて送り出す |
| **ミトコンドリア**（mitochondria） | ATPを作り、代謝も調節する | 二重膜で、内膜が大きく折れ込んで（cristae）表面積を稼ぐ。ATPを作るだけでなく、代謝物を通じて**核へ状態を報告する調節装置**。独自の小さなDNA（mtDNA）を持つ（→ 「エネルギー」・[[mito-quality-control]]） |
| **リソソーム**（lysosome） | 不要物を分解して再利用する | 内部が酸性（pH 5前後）の分解槽。古いタンパク質やオルガネラを**アミノ酸・脂肪酸・糖に戻す**。分解産物は材料として再利用される（→ [[autophagy]]） |
| **ペルオキシソーム**（peroxisome） | 脂質の代謝と酸化還元 | ミトコンドリアが苦手な**極長鎖脂肪酸のβ酸化**を担い、その反応で**過酸化水素（H₂O₂）が出る**。同時に **catalase を大量に抱えていて、その H₂O₂ をその場で水と酸素に分解する**——**H₂O₂ を出す反応と、それを分解する酵素が、同じ小器官の中にある**設計（→ [[oxidative-stress]]・[[sebum]]） |

ミトコンドリアのATP供給とリソソームの分解・再利用は、合成や輸送と並行して続きます。エネルギー不足や傷んだ成分の蓄積は、ほかのオルガネラの仕事にも影響します。

::: column ミトコンドリアは、もとは別の生物だった
ミトコンドリアは、真核細胞の祖先に取り込まれた好気性細菌に由来すると考えられています。これが**細胞内共生説（endosymbiosis）**です。二重膜であること、独自の環状DNAを持つこと、細胞分裂とは別に分裂することに、その名残があります。

長い進化の過程で遺伝子の大半は核へ移り、現在のヒトmtDNAには13種類のタンパク質をコードする遺伝子が残っています。そのため、ミトコンドリアの部品を作るには核DNAとmtDNAの両方が使われます（→ [[mito-quality-control]]）。

ヒトのmtDNAは、原則として母親から受け継がれます。受精後、精子由来のミトコンドリアは通常残らないためです。現代人のmtDNAを母系へさかのぼったときに行き着く共通祖先は、**ミトコンドリア・イヴ**と呼ばれます。

**母系で伝わることも、もとは別の生物だったことも、私は『パラサイト・イヴ』（1997年、原作は瀬名秀明）というホラー映画で知りました！** ミトコンドリアが、取り込まれて以来いつか宿主から独立しようと企てる物語です。ストーリーの細部は忘れても、この設定だけは一生忘れません。

**もとは別の生き物が自分の体のなかにいて、いまも一緒に働いている。** 子供ながらに、怖いというより**生物はこんなに未知なのか**と驚いたのを覚えています。
:::

## 3　分泌タンパク質は、ERで加工されてGolgiへ進む

### signal配列が、ERへの行き先を指定する

多くの分泌タンパク質では、合成が始まると鎖の先頭にある**signal peptide（シグナルペプチド）**が認識され、粗面ERへ運ばれます。

```flow
翻訳中の鎖に signal 配列がある → 粗面ERへ引き込まれる → ER内で折りたたみ・品質検査 → 小胞でGolgiへ → 分泌小胞 → 細胞外へ　／　ERへのsignal 配列がない → 細胞質で合成（別の移行シグナルで他の場所へ運ばれるものもある）
```

**分泌経路に入るかどうかは、あとから選ぶのではなく、設計図に書かれた"宛名"で最初から決まっています。** signal 配列がある鎖は翻訳の途中で認識され、リボソームごと粗面ERの膜に引き寄せられ、合成されながらそのままER内へ送り込まれます（co-translational translocation）。ERへのsignal 配列がないタンパク質は細胞質で合成されます。解糖系の酵素のようにそこで働くものも、別の移行シグナルによって核やミトコンドリアへ運ばれるものもあります。

### 折りたたみによって、働ける形になる

**タンパク質は、折りたたまれて初めて機能する形になります。** タンパク質はアミノ酸が一列につながった鎖として作られますが、鎖のままでは働きません。酵素の活性部位も、受容体の結合部位も、鎖の上では離れた位置にあるアミノ酸が、折りたたまれて初めて一か所に集まってできます。並びが正しくても、折りたたみが違えば働きません。

折りたたみ途中の鎖は、細胞にとって危険でもあります。完成したタンパク質では内側に隠れている疎水的な部分が、途中では外に出ています。細胞の中は分子が高密度に詰まっているので、露出したままの鎖は近くの分子とくっついて凝集します。だからERは折り損じを通さず、折り直せない鎖は分解へ回します。コラーゲンでいえば、三重らせんを組めなかった鎖は分泌されません。

### 折りたたみが追いつかないとき：ER stressとUPR

ERの折りたたみ能力を超えて、未完成や折り損じのタンパク質が溜まった状態が**ER stress（小胞体ストレス）**です。これを感知したERは、**UPR（unfolded protein response）**を起こします。UPRは、ERへ入る仕事量を減らし、折りたたむ能力と分解する能力を増やす応答です。

| UPRが行うこと | 細胞内で起こること |
|---|---|
| **新しく入る量を減らす** | タンパク質の翻訳を一時的に抑え、ERへ送り込まれる鎖を減らす |
| **折りたたむ能力を増やす** | chaperoneを増やし、ERの処理能力を高める |
| **折り直せないものを分解する** | ERから細胞質へ戻し、ubiquitinを付けてproteasomeで分解する（**ERAD**） |

この応答を始めるER膜のセンサーが**PERK・IRE1・ATF6**です。まずは三つの名前を覚えるより、**「入る量を減らす・折りたたむ力を増やす・直せないものを分解する」**という目的を押さえれば十分です。

ERADで一本ずつ処理できない凝集体や、傷んだER膜の一部は、autophagyによってlysosomeへ送られます。ERそのものを選んで回収する仕組みを**ER-phagy**と呼びます（→ [[autophagy]]）。それでもER stressが解消しない状態が続くと、細胞はapoptosisへ進むことがあります（→ [[cell-death]]）。

熱刺激で**HSF1からHSP70やHSP47**が誘導されるheat shock responseと、ER内の折り損じに対するUPRは、どちらもタンパク質の品質を守る応答ですが、感知する場所と経路は異なります。美容デバイスの熱応答は[[energy-devices]]、ER内でcollagenの三重らせん形成を助けるHSP47は[[fibroblast-collagen]]で扱います。

### 加工を終えたタンパク質を、小胞で運ぶ

分泌経路は、次の役割分担で進みます。

1. **ERで折りたたみと品質管理を行う。** 多くの分泌タンパク質は、酸化的なER内でS–S結合（ジスルフィド結合）を作り、chaperoneの介助を受けて折りたたまれます。
2. **小胞の内側で運ぶ。** 分泌するタンパク質は、ER内腔から輸送小胞へ入り、細胞質へ放出されずにGolgiへ届きます。
3. **ERを通ったあとの送り先を振り分けるのはGolgiです。** ERを出たタンパク質は Golgi で仕上げと**仕分け**を受けて初めて送り先が確定します。
4. **前へ送る輸送と、戻す輸送がある。** 分泌物はERからGolgi、細胞膜へ進みます。一方、輸送に使った成分やERへ戻すタンパク質は逆向きに回収されます。

## 5　補助的に押さえる構造

主役ではありませんが、後の章で顔を出します。

| 構造 | 何をするか | 押さえどころ |
|---|---|---|
| **細胞膜** | 内と外を仕切り、物質の出入りを制御する | 通す・通さないの規則は分子の側の性質で決まる（→ [[membrane-transport]]） |
| **endosome**（エンドソーム） | 外から取り込んだものを仕分ける小胞 | 分解へ回すか、膜へ戻すかを決める（→ [[membrane-transport]]） |
| **lipid droplet**（脂肪滴） | 中性脂肪をためる小滴 | 脂肪細胞では細胞の大部分を占める主役になる（→ [[adipose]]） |
| **ECM** | 細胞の"外"の足場 | 足場であると同時に、細胞に情報も伝える（→ [[ecm]]） |
| **cytoskeleton**（細胞骨格） | 形の維持・運搬・張力の感知 | **actin filament**＝膜直下で収縮し張力を生む／**microtubule**＝小胞とオルガネラを運ぶレール／**intermediate filament**＝引っ張りに耐える芯（表皮の keratin）。**integrin** で ECM に接着した点で細胞骨格を引くと、足場の硬さと張力が細胞内シグナルに変換される＝**mechanotransduction**（→ [[ecm]]） |

## この章の到達点

1. 細胞の仕事は単一のオルガネラでは完結しない。**分泌タンパク質を1本外へ出す**という一つの仕事に、核・リボソーム・粗面ER・Golgi が順に関与し、ミトコンドリアとリソソームが全工程で同時に働く。
2. 7つのオルガネラはそれぞれ別の環境を持つ（酸化的なER内、pH 5前後のリソソーム、catalase を抱えたペルオキシソーム）。担当する仕事は、その環境で何ができるかで決まっている。
3. この順番は覚えるだけの並びではない。**多くの分泌タンパク質はsignal 配列によってERへ入り、加工・品質管理を経てGolgiで仕分けられる。**だからこの順番になる。**どの工程が滞っても出力は落ちる。**
4. ERの折りたたみ能力を超えて未完成のタンパク質が溜まると**ER stress**になり、**UPR**が入る量を減らし、折りたたみと分解の能力を高める。
5. 産生量には、材料・エネルギーの供給と、合成・加工・輸送の各工程が関わる。**全体を制限している律速段階**を考える。
