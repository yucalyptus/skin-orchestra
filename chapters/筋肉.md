> HIFEM、LIFTON、体外衝撃波など、随意運動によらず筋を収縮させる機器が、輪郭・引き締めの治療として使われています。輪郭を支えるもう一つの組織として、この章は筋肉を扱います。


## この章の一言

> **使わない筋は萎縮し、動いた筋は myokine を出します。**
>
> だから筋の話は「鍛えると太くなる」だけではありません。**萎縮（使わない・加齢）と拘縮（過緊張）という二方向の崩れ**を防ぎ、**収縮したときに出る分泌**を回すこと——「筋を健全に保つ」の中身はこの二つです。


## 1　筋の崩れ方は二方向 ―― 萎縮と拘縮

![筋量（断面積・筋厚をMRI/CT/超音波/DXAで測る）、筋力（最大随意収縮・1RM・握力）、筋質（筋力÷筋量、脂肪浸潤・線維化・ミトコンドリア機能）の3枚。中段は筋力が筋量以外に神経適応・腱・関節可動域・測定条件でも動くこと、下段はトレーニング初期（筋量はわずかでも筋力が上がる）と加齢（筋量以上に筋力が落ちる）の乖離](figures/muscle_筋量筋力筋質.png)

筋は「増える／増えない」の一軸ではなく、**反対向きの二つの崩れ方**をします。

**① 萎縮（atrophy）――使わない・年を取る。**
筋タンパクは常に合成と分解が同時に走っています（→ [[dna-to-protein]]）。負荷が抜けると分解側が勝ちます。分子で言うと、Akt–mTORC1 の入力が落ちて転写因子 **FoxO** の抑制が外れ、筋特異的な E3 ubiquitin ligase の **MuRF1（TRIM63）** と **atrogin-1／MAFbx（FBXO32）** が誘導されて、ubiquitin–proteasome 系がミオシン重鎖などを削っていく。数日の不動でも動き出す速い反応です。

加齢の萎縮（sarcopenia）はこれに三つが重なります。**運動単位の脱落と神経筋接合部の変性**（denervation と再支配の繰り返し）、**type II 線維優位の萎縮**、そしてロイシンや負荷に対する mTORC1 応答が鈍る **anabolic resistance**（→ [[amino-acids]]・[[mtorc1]]）。抜けた場所は脂肪と線維組織に置き換わります（**myosteatosis**）。図の右下——加齢では**筋量の減少以上に筋力が落ちる**——の中身がこれです。

**② 拘縮・過緊張――使いすぎる側の崩れ。**
顔ではむしろこちらが目に付きます。咬筋の持続的な食いしばり、皺眉筋・前頭筋の常時収縮、広頸筋のバンド。短縮位で使われ続けた筋は、筋節数の減少と筋周囲 ECM への collagen 沈着で**伸びにくく**なります。萎縮とは逆向きですが、これも「健全でない」状態です。ここに用いるのがボツリヌストキシン（→ [[botulinum]]）。

**なぜ顔で効くのか。** 表情筋は骨から起こって**皮膚に停止する**皮筋で、腱を介さず皮膚を直接引きます。だから筋の張力はそのまま皮膚の形になる。支持が落ちれば下垂に、過緊張が続けば線が刻まれる。たるみを層で分ける議論は → [[sagging]]。

そして図が示すとおり、**量・力・質は別々に測る指標**です。「引き締まった」という臨床の言葉には、量の増加・神経動員の改善・脂肪の減少・むくみの消退が混ざっています。


## 2　動いた筋は myokine を出す

![上段は運動神経の活動電位→ACh放出→T管の脱分極→DHPR/RyR→筋小胞体からのCa²⁺放出→トロポニンC→架橋形成という興奮収縮連関の9段。下段は同じ収縮から分かれる二つの適応で、左は抵抗運動・アミノ酸→mTORC1→筋肥大（量）、右は持久運動→AMPK/PGC-1α→ミトコンドリアと毛細血管の増加（質）。中央にATP供給の3系が重なって置かれる](figures/muscle_筋肉.png)

収縮した筋がすることは、力を出すことだけではありません。**骨格筋は内分泌器官として振る舞い、収縮に伴って液性因子を分泌します。** これを **myokine（マイオカイン）** と呼びます。20年ほどで300以上が報告されています。

| myokine | 出どころ・上流 | 何をするとされるか |
|---|---|---|
| **IL-6** | 収縮する筋線維そのもの（グリコーゲン枯渇で増強） | 運動中に一過性に大量に出て、**IL-10・IL-1ra を誘導する抗炎症側**に働く。マクロファージ由来の慢性炎症の IL-6 と同じ分子だが、出どころと時間経過が違う |
| **irisin** | PGC-1α → **FNDC5** の切断産物 | 白色脂肪の beiging・骨代謝。ヒトでの循環量の定量には方法論的な議論がある |
| **IGF-1（局所型）** | 機械的負荷 | オートクリン／パラクリンに mTORC1 を回し、肥大側へ |
| **myostatin（GDF-8）** | 筋自身 | **負の制御因子**。これが働くと筋量は抑えられる。抵抗運動で低下する |
| **decorin** | 収縮する筋 | myostatin を結合して中和する。**同じ分子が真皮では collagen 線維形成を制御する small leucine-rich proteoglycan**（→ [[fibroblast-collagen]]） |
| **IL-15・SPARC・BDNF・apelin・FGF21** | 収縮筋 | 脂質代謝・血管・骨・神経など、離れた臓器への作用が報告されている |

ここが「筋トレは肌にいい」という話の生化学的な出どころです。ただし段は分けます。

- **収縮した筋が myokine を分泌し、血流に出る**：確立した細胞生物学。
- **それが皮膚に届いて線維芽細胞の振る舞いを変える**：機序として想定できるが、**ヒトで示されていません**。decorin のように筋と真皮で同じ分子が働く例はありますが、**筋由来 decorin が皮膚の ECM を変えるという証拠ではありません**。
- 一方、**萎縮した筋は輪郭の支持を失う**——ここは分泌の話を一切通さずに言えます。

> 「筋を動かすと美容にいい」の確かな部分は、**myokine の全身作用ではなく、萎縮を起こさせないこと**の側にあります。myokine は、そこに乗るかもしれない上乗せとして、点線で置いておきます。


## 3　適応は二方向 ―― 量（mTORC1）と質（AMPK–PGC-1α）

![左は抵抗運動・機械的張力・leucine・インスリンからmTORC1→p70S6K/4E-BP1→筋タンパク合成→筋線維肥大。右は持久運動・ATP低下・Ca²⁺シグナルからAMPK→p38/CaMK→PGC-1α→ミトコンドリア新生・酸化酵素・毛細血管の増加。中央に「二者択一ではない」。下段は運動直後のシグナル→数時間〜数十時間の遺伝子発現とタンパク質合成→週〜月の表現型変化という時間スケール](figures/muscle_mTORC1とAMPK_PGC1a.png)

筋は、[[ampk-mtor]]の「合成（mTORC1）と点検（AMPK）」の対比がそのまま目に見える組織です。対比そのものは[[ampk-mtor]]の担当。筋に固有なのは二点だけ。

**AMPK の下流に `PGC-1α` が置かれていること。** mitochondrial biogenesis（→ [[mito-quality-control]]）を駆動する転写共役因子で、持久的刺激で誘導されると**線維は太らないままミトコンドリアと毛細血管が増える**。量が変わらずに質が上がる。irisin の上流でもあります（§2）。

**筋線維型があること。** type I（酸化的・疲れにくい）と type II（解糖系優位・太くなりやすい・加齢で先に萎縮する）は代謝特性が違い、PGC-1α 系が回れば酸化的な方向へ、mTORC1 系が回れば断面積が増える方向へ寄ります。

![上はcross-bridge cycleの4段（ATP結合でミオシンが解離→加水分解で頭部が起きる→Pi放出でパワーストローク→ADP放出）。下段左は収縮（Ca²⁺放出とトロポニンCへの結合）、右は弛緩（SERCAがATPを使ってCa²⁺を筋小胞体へ戻す）。最下段のグラフはphosphocreatine・解糖系・酸化的リン酸化が「切り替わるのではなく常に重なって働く」ことを示す](figures/muscle_収縮と弛緩のATP.png)

収縮そのもののエネルギー——cross-bridge cycle と、Ca²⁺ を汲み戻す SERCA が**どちらも ATP を要ること**——は[[glycolysis]]・[[tca-cycle]]・[[electron-transport]]で扱いました。ここで要るのは一点だけで、**強く長く働かせるほどミトコンドリアの酸化能が効いてくる**ので、萎縮した筋では「動かせる総量」自体が頭打ちになる、ということです。


## 4　機器 ―― 収縮を作る側と、機械刺激を入れる側

![上段は確立している経路（皮膚を介した電磁場→末梢運動神経の反復脱分極→運動単位の同期的動員→不随意の強い収縮）。中段は研究で測れるアウトカムがMRI/CTの断面積・超音波の筋厚・筋力・外観と周径・脂肪厚に分かれ、互いに置き換えられないこと。下段は読み方の3段階——収縮誘発は確立、筋厚や外観の変化は小規模研究レベル、運動と同等・長期の機能改善は未確立](figures/muscle_HIFEMのエビデンス評価.png)

臨床で使われている機器は、**入口の物理がそれぞれ違います。** ひとまとめに「筋に効く機械」と呼ぶと、何を期待してよいかを取り違えます。

**① HIFEM（high-intensity focused electromagnetic）**
コイルが作る**時間変化する磁場**が組織内に誘導電流を起こし、**末梢運動神経を脱分極**させます。電流を皮膚から流し込む電気刺激（EMS）と違い、磁場は脂肪層や皮膚のインピーダンスの影響を受けにくく、皮膚痛が出にくい。随意最大収縮を超える **supramaximal contraction** を、1セッションで数千回反復させる設計です。臨床データが最も多いのは体幹（腹直筋・殿筋）。RF を重ねて脂肪側にも同時に作用させる機種、顔面（前頭筋・大頬骨筋）を狙って真皮への RF を組み合わせた機種もあります。

**② 顔面用の筋刺激デバイス（LIFTON など）**
経皮的に電流または電磁場を与え、表情筋を反復収縮させる機器群です。**刺激様式（電流か磁場か）・周波数・出力・到達深度は製品ごとに異なり、機種名から機序を推定できません**。RFと同期させる高強度の電気刺激、家庭用の高周波NMES、12週のNMES試験——同じ「顔の筋刺激」でも入口の物理も評価項目も別です。顔面では標的が小さく浅く、**体幹の HIFEM データをそのまま外挿できない**——これが顔面用機器を読むときの最初の注意点です。

**③ 体外衝撃波（extracorporeal shockwave therapy, ESWT）**
これは**収縮を起こす機器ではありません。** 音響パルスによる機械刺激で、焦点式（focused）と、圧搾空気でプロジェクタイルを加速して表層に発散させる放散式（radial）があります。作用の入口は mechanotransduction（→ [[ecm]]）——細胞への機械的ストレスから NO・VEGF・血管新生・ECM リモデリングが立ち上がる方向で、筋に対しては主に**過緊張やトリガーポイントを緩める側**、皮下では線維隔壁に対して働くと説明されます。**筋を肥大させる機器ではない**という点で、①②とは列が違います。

**そのうえで、収縮を作れることと臨床効果は分けます。**

1. **収縮の誘発（生理）は確立**。これはできる。
2. **収縮の誘発 ≠ ヒトでの筋肥大・輪郭改善**。研究はメーカー主導・小規模・短期・画像評価中心のものが多く、独立した長期データは限られる。MRI／超音波での「筋厚の変化」報告も、**浮腫・測定条件・脂肪層の変化**との切り分けが不十分なことがある。「筋量↑」と「脂肪↓」を同時に謳う場合、どちらが輪郭に効いたかは分離できません（→ [[adipose]]と同じ問題）。
3. **収縮を作っても、材料と回復が要る**。肥大には mTORC1 を回す負荷に加えてアミノ酸・成長因子・休息が必要です（→ [[mtorc1]]）。受動的な収縮だけで随意トレーニングと同等の適応が起こるとは限らない。

> ここでも「デバイスは刺激を入れる、組織を作り直すのは細胞」（→ [[energy-devices]]）の原則が効きます。機器が確実に提供しているのは**収縮という刺激**であって、筋量そのものではありません。


## この章の到達点

![[[muscle]]のまとめ。興奮収縮連関、ATPの3つの用途（ミオシンの解離・頭部の再セット・SERCAによるCa²⁺回収）、重なって働くATP供給、量の適応（mTORC1）、質の適応（AMPK–PGC-1α）、そして評価の原則（電磁刺激の収縮誘発と長期臨床効果を同一視しない）。結論は「刺激×栄養×回復×反復が適応を決める」](figures/muscle_まとめ.png)

1. **筋の崩れ方は二方向。** 萎縮は FoxO → **MuRF1・atrogin-1** による ubiquitin–proteasome 系の分解が主で、加齢ではこれに運動単位の脱落・**type II 優位の萎縮**・**anabolic resistance**・myosteatosis が重なる。拘縮・過緊張は逆向きの崩れで、ボツリヌストキシンの適応（→ [[botulinum]]）。
2. **表情筋は皮膚に停止する皮筋**なので、張力がそのまま輪郭に出る。だから顔では萎縮も過緊張も見た目に直結する（→ [[sagging]]）。
3. **収縮した筋は myokine を分泌する**（IL-6・irisin・IGF-1・myostatin と decorin など）。**分泌が起きることは確立、それが皮膚のアウトカムを変えることは未確立。** 確かなのは「萎縮させないこと」の側。
4. **適応は量（mTORC1）と質（AMPK–PGC-1α）で別方向**。刺激様式でどちらが回るかが変わる。**筋量・筋力・筋質は別指標**で、筋力の初期変化は神経性のことが多い。
5. **機器は入口で分ける。** HIFEM＝磁場で運動神経を脱分極させ supramaximal な収縮を作る／顔面用の筋刺激デバイス＝刺激様式は製品ごとに異なる／**体外衝撃波＝収縮ではなく機械刺激**。収縮誘発は確立、ヒトでの筋肥大・輪郭改善は独立検証が限られ、脂肪変化との切り分けも課題。

### Evidence meter

- 不動・除神経で FoxO → MuRF1／atrogin-1 が誘導され筋タンパクが分解される：**確立した細胞生物学**
- 加齢に伴う type II 線維優位の萎縮・運動単位の脱落・anabolic resistance：**確立した生理**
- cross-bridge cycle・SERCA の ATP 依存性：**確立した生化学**
- mTORC1＝筋タンパク合成／AMPK–PGC-1α＝mitochondrial biogenesis：**確立した細胞生物学**
- 収縮した骨格筋が myokine（IL-6・irisin・decorin など）を分泌する：**確立した細胞生物学／個々の myokine のヒトでの生理的意義は検証途上（irisin は定量法に議論あり）**
- myokine を介して運動がヒトの皮膚アウトカムを改善する：**未確立**
- 電磁刺激が骨格筋の収縮を誘発する：**確立した生理**
- 電磁刺激機器がヒトで有意な筋肥大・輪郭改善をもたらす：**製品・部位ごとに検証が必要（独立・長期データが限定的。体幹のデータを顔面へ外挿しない）**
- 体外衝撃波が mechanotransduction を介して血管新生・ECM リモデリングを起こす：**細胞生物学として確立／美容アウトカムは製品・適応ごとに検証が必要**
- 受動的電磁収縮が随意トレーニングと同等の適応を生む：**未確立**
