# 生化学で見る美容医療 ― 皮膚の下のオーケストラ

*An Orchestra Beneath the Skin: The Biochemistry of Aesthetic Medicine*

美容皮膚科医・美容医療従事者向けに、**細胞生物学・生化学の基礎を思い出し、自分たちが美容でやっている施術が細胞・分子レベルで何をしているのかを理解する**ための教材です。

「新しい知識の詰め込み」ではなく **学び直し**。臨床でふだん意識しない基礎を、施術と結びつけて腑に落とすことを目的にしています。

## 全体を貫く流れ

> 細胞の構造 → エネルギー代謝 → 品質管理 → 加齢変化 → 美容施術への応答

前半は治療を前面に出さず基礎を積み、**美容治療はセクション「美容皮膚科」から接続**します。

## 構成

```
Ⅰ 基礎 ― 細胞のしくみを思い出す
    細胞の地図 / 情報をどう読むか / エネルギー /
    材料を感知し作る / 掃除と作り直し / 傷つくとどうなるか / 加齢で何が変わるか
Ⅱ 美容皮膚科 ― 局所に施術する
    皮膚・脂肪・筋の生化学（治療は出さない） / 外用 / 注射 / デバイス
Ⅲ 美容内科 ― 全身から入れる
おわりに
```

**本数はここに書かない**（書くと必ず古くなる）。実数は `資料/章一覧.md`（自動生成）と、表紙のスコア表が持つ。

- **治療は手段で分けています**（外用／注射／デバイス）。部の見出しが臨床の語彙になり、**新しい章の行き先が一意に決まる**ためです。
- **主訴（しみ・たるみ・赤み）では分けません。** 1本の章が複数の主訴にまたがるからです（IPLはしみと赤み、フラクショナルはたるみ・毛穴・小じわ）。主訴からは**索引ページ**で引きます。
- 美容皮膚科と美容内科の境目は投与経路ではなく、**標的が皮膚の特定構造か、全身か**です。内服でもトラネキサム酸は美白外用の章、イソトレチノインは皮脂の章にあります。

章ごとの一覧は **[`資料/章一覧.md`](資料/章一覧.md)**（自動生成）にあります。

## この教材に章番号はない

章は **`id`**（英字）で指します。`id` はそのまま公開URLになります（`glycolysis` → `glycolysis.html`）。

- **章を足す＝`目次.yml` に id を1行足すだけ。**他は何も動かない。
- 章番号がないので、章を挿入・分割・並べ替えしても、ファイル名も相互参照も図もURLもずれない。
- 読者にも章番号は見せません。位置は部の見出しと並び順が示します。
- **本文には順序語（「次章」「前章」）を書きません。** 並べ替えで壊れるからです。「次に何を読むか」はビルドが `目次.yml` から自動で出します。

## 少しずつ公開する

**著者が読んで確定した章だけを公開します。**週ごとに増えていく形です。

| コマンド | 出力 | 中身 |
|---|---|---|
| `python3 build.py` | `docs/`（公開用） | **`status: approved` の章だけ** |
| `python3 build.py --preview` | `_preview/`（ローカル専用） | **全章**。statusバッジ付き |

`_preview/` は `.gitignore` に入っているので、公開されることはありません。著者のチェックはこちらで行います。
未公開の章は、目次に薄く「準備中」と出ます（リンクなし）。未公開章への `[[id]]` は、公開ビルドで自動的にリンクが外れ、章題だけが残ります。

**公開の順番は決めていません。**著者が確認できた章から出します。だから読者には「いつ何が増えたか・何を直したか」が見えている必要があります。

| 出るもの | 元データ |
|---|---|
| 目次の **NEW / 更新** バッジ | front matter の `history` の最新日から14日以内 |
| 章ページの「公開 ◯◯／最終更新 ◯◯」 | `published` / `history` |
| **更新履歴ページ**（日付降順で全件） | 全章の `history` を集約 |
| 表紙の「**最近の更新**」（直近5件） | 同上 |

章を直したら front matter の `history:` に1行足すだけです。バッジは手で貼りません。

## 章の書き方

各章の先頭に front matter を置きます。**本文に H1（`# 章題`）は書きません**——章題は `title` が正典で、ビルドが見出しを出します。

```yaml
---
id: glycolysis
title: 解糖系
subtitle: glycolysis      # 英語または短い副題（任意）
kind: basic               # basic（基礎）/ applied（各論）/ conclusion
status: draft             # draft → review → approved
published: 2026-08-20     # 初公開日（approved にしたとき入れる）
history:                  # 更新履歴ページとバッジの元データ
  - {date: 2026-08-20, note: 初公開}
適応: [しみ, 肝斑]         # 主訴索引に載せるとき（任意・各論の章のみ）
手段: [デバイス]           # 外用 / 注射 / デバイス / 経口・点滴
---
```

**`id` は一度公開したら変えません。**変えると読者のリンクが切れます。
`title` やファイル名はあとから変えても壊れません。

### 他の章を参照するとき

```
[[glycolysis]]で見たとおり            → 「解糖系で見たとおり」＋リンク
[[glycolysis|解糖系の章]]             → 表示文字を指定したいとき
```

存在しない id を書くとビルドが止まります。未公開章へのリンクは、公開ビルドでは自動的にリンクが外れてタイトルだけになります。

### 書かないもの

本文が並び順に依存すると、章を1本足しただけで壊れます。

| 書かない | 代わりに |
|---|---|
| 「次章」「前章」 | `[[id]]` で章題を明示する |
| 「第N章」「第N部」 | `[[id]]` ／ 部名・セクション名 |
| 「ここで◯◯は終わりです」「ここから△△に入ります」 | **書かない。**`目次.yml` の部 `intro` に書く |

章末の送り文は、位置ではなく**内容の関係**を述べます。「[[biostimulators]]では、同じ注射でも体積の主役が変わります」——これなら並べ替えても壊れません。

## 画像について

本文からは次の記法で参照します。

```
![図の説明](figures/glycolysis_乳酸の行き先.png)
```

命名規則は `<章id>_<図名>.png`。図名の部分は日本語で構いません。1章に複数図を持てます。
`![…]` の説明文がそのままHTMLのキャプションになります。

| ディレクトリ | 形式 | 役割 |
|---|---|---|
| **`figures/`** | PNG | **ソース（正）**。本文mdはここを参照。画像を追加/差し替えるのはここ |
| **`docs/images/`** | **WebP** | **公開用**。ビルドが自動生成するので手で編集しない |

流れは **`figures/`（ソースPNG）→ ビルド → `docs/images/`（公開WebP）** の一方向です。

### ビルド方法

```
python3 gen_index.py                  # 資料/図版台帳.md・資料/章一覧.md を再生成
.venv/bin/python build.py             # 公開ビルド（approved のみ）→ docs/
.venv/bin/python build.py --preview   # 全章プレビュー → _preview/
```

**`.venv` は Pillow を入れた作業用の仮想環境**です（`.gitignore` 済み。マシンごとに作ります）。

```
python3 -m venv .venv && .venv/bin/pip install -q Pillow
```

**PNG→WebP(q85) の変換には Pillow が要ります。**容量が約1/8になります。
Pillow がないと画像が PNG のまま公開されてサイトが肥大するため、`build.py` は Pillow が無い python では**冒頭で止まります**（Pillow を持つ別の python3 が見つかれば自動でそちらに切り替えて実行し直します）。

止まったときは Pillow を入れてください：
```
python3 -m pip install --user Pillow
# PEP 668 で弾かれる場合（Homebrew の python）は一時venvが安全：
python3 -m venv /tmp/webp_venv && /tmp/webp_venv/bin/pip install -q Pillow
/tmp/webp_venv/bin/python build.py
```

**ビルド後は `git status` を見て、`docs/images/` に `.png` が混入していないか確認してください。**
`.png` が追加され `.webp` が消えていたら、それが Pillow 無しで流した事故です。
